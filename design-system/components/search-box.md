# search-box

search-box は、ユーザーが必要な情報を素早く見つけるための検索専用の入力コンポーネントです。キーワードの入力に応じて、候補表示や検索実行を行い、コンテンツ探索の効率を高めます。

## いつ使うか
- キーワード検索によってコンテンツを探索させたいとき
- 検索候補をリアルタイムに表示し、ユーザーの入力を補助したいとき
- フィルタリングUIにおける検索入力が必要なとき

## いつ使わないか
- フォームへの一般的なテキスト入力には text-field を使用します
- ラベルや補足テキストを伴う検索入力欄が必要な場合は search-box-unit を使用します
- text-field との違い：text-field は汎用のテキスト入力欄です。search-box は検索専用の見た目（検索アイコン・クリアボタン）と振る舞いを持ちます。検索目的の入力欄には search-box を使用します
- search-box-unit との違い：search-box-unit は label-unit を組み合わせ、ラベル・必須バッジ・補足テキストを含むフォーム項目をワンセットで表現します。ラベルが不要な場合は search-box を直接使用します

## バリアントプロパティ
| プロパティ | 値 |
|---|---|
| variant | `primary` / `secondary` |
| size | `medium` / `large` |
| state | `default` / `hover` / `focus` / `error` / `error-hover` / `error-focus` / `disabled` |

## variant の使い分け

### variant（種類）
| variant | 使いどころ |
|---|---|
| `primary` | ページ全体やテーブル全体を対象とした検索に使用します。一覧ページ上部に配置するキーワード検索や、テーブル内のレコード絞り込みなど、画面の主要コンテンツを対象にした検索機能として機能します |
| `secondary` | フォーム入力の一部として使用します。セレクトボックスの候補を検索して絞り込む場面や、入力項目に紐づく検索補助など、1つの入力要素としてフォームに組み込む用途を想定しています |

使い分けの判断軸としては、検索が「画面の主機能」なのか「入力操作の一部」なのかで判断します。

### size（サイズ）
- `medium`：標準サイズです
- `large`：やや大きなサイズです。視覚的な存在感を高めたい場面や、タッチ操作が主なスマートフォン向けの場面に適しています

## コンテンツルール
- プレースホルダーテキストは、何を検索できるかを端的に示す文言にします。ユーザーが何を入力すべきかが一目でわかる言葉を選びます
- 入力値がある場合はクリアボタン（×）を表示します。クリアボタンは入力値がないときは非表示にします
- 検索アイコンは常に表示します
- フォーカス中に文字を入力すると、入力に応じた候補の [suggestion](./suggestion.md) が表示されます

## Do
- 検索専用の入力欄として使う
- プレースホルダーで検索対象のヒントを表示する

## Don't
- フォームへの一般的なテキスト入力に使わない（text-field を使う）
- ラベルが必要な場面で search-box を単体で使わない（search-box-unit を使う）
