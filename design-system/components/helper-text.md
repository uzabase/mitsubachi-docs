# helper-text

helper-text は、入力要素に付随して、入力内容の補足情報やバリデーション結果を表示する最小単位のメッセージコンポーネントです。

## 使いどころと選び方

### 使うべきシーン
- フォームの入力要素（[text-field](./text-field.md) や [text-area](./text-area.md) など）の直下に配置し、エラーメッセージや入力のヒントを表示するとき。
- 入力のバリデーション結果をユーザーに伝えるとき。
- 任意の操作の結果（成功・警告など）を、特定の入力要素と関連付けて伝えるとき。

### 使わないほうがよいシーン
- システム全体への通知やメッセージには、[snackbar](./snackbar.md) や [banner](./banner.md) などのコンポーネントを使用します。
- 単一の入力要素に対して複数のメッセージを同時に表示したい場合は、[helper-text-group](./helper-text-group.md) を使用します。

### 他コンポーネントとの違い・使い分け
- [snackbar](./snackbar.md): 操作の結果を一時的に表示するグローバルな通知には snackbar を使用します。特定の入力要素に紐づかないメッセージには snackbar が適切です。
- [inline-notification](./inline-notification.md): helper-text と同じくインライン表示ですが、個々の入力要素ではなく**フォームやコンテンツ領域全体**に紐づくメッセージに使います。フォーム送信結果など、複数の要素をまたぐ通知に向いています。
- [banner](./banner.md): helper-text や inline-notification のような特定の文脈への紐づきはなく、**画面全体**に影響する重要な状態変化（システム障害・メンテナンスなど）を伝えます。オーバーレイで表示され、自動消去されません。

## 構成とルール

### バリエーション・状態

| プロパティ | 値 |
|---|---|
| size | `small` / `medium` / `large` |
| status | `error` / `information` / `success` / `warning` |

#### size（サイズ）
- `small`
- `medium`
- `large`

親コンポーネント（text-field など）のサイズに合わせて選択します。

#### status（ステータス）
- `error`：入力内容に問題があることを伝えます。テキストはエラーカラーで表示されます。
- `information`：入力に関する補足情報を伝えます。
- `success`：入力が正常に完了したことを伝えます。
- `warning`：入力内容に注意が必要な点を伝えます。

### コンテンツルール
- アイコンとテキストで構成されます。アイコンはステータスに応じて自動的に切り替わります。
- テキストは1行を超えて複数行にまたがることができます。
- テキストは具体的かつ簡潔に記述します。ユーザーが次に取るべきアクションを理解できる内容にします。
- error ステータスのテキストはエラーカラーで表示し、それ以外のステータスのテキストは通常カラーで表示します。

## 振る舞い
- helper-text 自体は静的な表示のみを行います。クリックやタップ操作を受け付けません。
- 入力要素のバリデーション状態に応じて、ステータスを切り替えます。
- エラーが解消された場合、helper-text を非表示にするか、別のステータスに切り替えます。

## 役割と目的
- helper-text は、ユーザーの理解や判断をサポートする最小単位のメッセージコンポーネントです。
- テキストフィールド（[text-field](./text-field.md) や [text-area](./text-area.md) など）やその他の入力要素に付随して、入力内容の補足情報を表示します。
- エラー・情報・成功・警告の4つのステータスに応じたアイコンとテキストを組み合わせることで、ユーザーに現在の状態を視覚的に伝えます。
- バリデーション（入力値の検証）の結果や、入力に関する注意事項などのフィードバックを提供します。
