# loading

Loading（ローディング）は、処理中であることをユーザーに知らせ、完了までの待機を促すコンポーネントです。回転するリング状のアニメーションにより、動作中であることを直感的に示します。

## いつ使うか
- データの取得・送信など、完了まで時間がかかる処理の実行中
- コンテンツ領域が描画される前の待機状態
- ユーザー操作に対してシステムが応答しているとフィードバックが必要な場面

## いつ使わないか
- 処理時間がほぼゼロに近く、ちらつきが生じる可能性がある場合
- 進捗状況（何%完了など）を具体的に示す必要がある場合（Progress Bar など別コンポーネントを検討します）
- **Progress Bar**（未定義）: 処理の進捗割合をパーセントやバー幅で表現したい場合に使います。Loadingは進捗が不明・計測不能な処理に適しています
- **Skeleton**（未定義）: ページやコンテンツの構造を維持しながら読み込み中を示したい場合に使います。Loadingはコンテンツ構造が不確定なときや、ページ全体・小さなボタン内など範囲が狭い場面に適しています

## バリアントプロパティ
| プロパティ | 値 |
|---|---|
| タイプ | `AI` / `Standard` |
| size | `medium` / `large` / `x-large` / `2x-large` / `3x-large` / `4x-large` |

## variant の使い分け

### タイプ
| タイプ | 使いどころ |
|---|---|
| `AI` | グラデーションカラーのリング。AI機能に関連する処理中を示す場面で使います |
| `Standard` | モノクロ（ダーク）のリング。通常の処理中を示す場面で使います |

### サイズ
| size | 用途の目安 |
|---|---|
| `medium` | 最小。テキスト付きボタン内など狭い領域 |
| `large` | 小さなUI要素内 |
| `x-large` | 標準的なインライン表示 |
| `2x-large` | やや広い領域 |
| `3x-large` | コンテンツ領域内の中程度の表示 |
| `4x-large` | 最大。ページ全体・モーダルオーバーレイなど広い領域 |

## コンテンツルール
- Loadingコンポーネント自体にテキストラベルは含みません
- 必要に応じて、周辺のUIで「処理中です」などの補足テキストを別途配置します
- AIタイプはAI機能の処理に限定して使います。通常のデータ取得などにAIタイプを流用しません

## Do
- 処理中であることをユーザーに伝えるために使う
- 処理が完了したらLoadingを非表示にしてコンテンツを表示する

## Don't
- AIタイプを通常のデータ取得に流用しない
- 処理時間がほぼゼロの場面で使わない（ちらつきの原因になる）
