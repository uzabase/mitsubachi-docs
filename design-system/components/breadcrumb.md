# breadcrumb

breadcrumb（パンくずリスト）は、現在のページがサイト内のどの階層に位置しているかを示し、上位ページへ素早く戻るためのナビゲーションコンポーネントです。

## 使いどころと選び方

### 使うべきシーン
- 2階層以上の深さを持つサイト構造で、ユーザーが現在地を把握しながら上位ページへ移動する必要がある場面
- ユーザーが複数の階層を経由して到達するような詳細ページ（例：企業詳細ページ、レポート詳細ページなど）

### 使わないほうがよいシーン
- 階層構造がない、または1階層のみのページ（breadcrumbは不要）
- モーダルやダイアログ内など、独立したナビゲーションが文脈に合わない場所

### 他コンポーネントとの違い・使い分け
- [tab](./tab/index.md) との違い: tabは同一階層内でコンテンツを切り替える用途に使用します。breadcrumbは階層をまたいだページ移動を表示し、tabは同一階層内での切り替えに使用します
- **link** との違い: linkは個別のテキストリンクとして単体で使用します。breadcrumbは複数の階層パスを連続して表示するためのまとまりとして使用します

## 構成とルール

breadcrumbは以下の要素で構成されます。

| 要素 | 説明 |
|---|---|
| **リンク項目（上位ページ）** | 各上位階層のページ名をテキストリンクとして表示します。クリックすると対象ページに遷移します |
| **セパレーター** | 階層の区切りを示すアイコン（右向きシェブロン）で、各リンク項目の間に配置されます |
| **現在のページ（最末尾項目）** | 現在表示しているページの名前を非リンクのテキストとして表示します |

### バリエーション・状態

各リンク項目が取りうる状態は以下のとおりです。

| プロパティ | 値 |
|---|---|
| state | `default` / `hover` / `focus` / `active` / `current` |

| 状態 | 説明 |
|---|---|
| **Default** | 通常のリンク状態 |
| **Hover** | カーソルが重なった状態。視覚的なフィードバックを提供します |
| **Focus** | フォーカスが当たった状態。フォーカスリングが表示されます |
| **Active** | クリックした瞬間の状態 |
| **Current（最末尾）** | 現在のページを示す非リンク状態。操作不能として表示されます |

### コンテンツルール
- 各項目のラベルには、対応するページの正式名称を使用します
- ラベルのテキストは折り返しを生じさせないよう、簡潔に記述します
- 最末尾の現在ページ項目はリンクとして機能させません
- セパレーターはコンテンツではないため、読み上げの対象から除外します

## 振る舞い
- **リンク項目クリック時**: 対象の上位ページへ遷移します
- **現在ページ（最末尾）**: クリックしても遷移は発生しません。操作不能な状態として表示します
- **フォーカス・キーボード操作**: Tabキーで各リンク項目間をフォーカス移動でき、Enterキーで対象ページへ遷移します

## Do
- 階層の深いページで現在地を示すために使う
- 各項目のラベルにはページの正式名称を使う

## Don't
- 1階層のみのページで使わない
- モーダルやダイアログ内で使わない

## 役割と目的
- **解決する課題**: 階層の深いサイト構造において、ユーザーが現在地を把握しにくい問題を解決します
- **UI上での基本的な役割**: ページ上部に表示され、現在のページとその上位階層をリンクとして一覧表示します
- **ユーザーにとっての意味**: 任意の上位ページに素早く移動でき、サイト内での現在位置を常に把握できます
