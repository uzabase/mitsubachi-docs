# breadcrumb

breadcrumb（パンくずリスト）は、現在のページがサイト内のどの階層に位置しているかを示し、上位ページへ素早く戻るためのナビゲーションコンポーネントです。

## いつ使うか
- 2階層以上の深さを持つサイト構造で、ユーザーが現在地を把握しながら上位ページへ移動する必要がある場面
- ユーザーが複数の階層を経由して到達するような詳細ページ（例：企業詳細ページ、レポート詳細ページなど）

## いつ使わないか
- 階層構造がない、または1階層のみのページ（breadcrumbは不要）
- モーダルやダイアログ内など、独立したナビゲーションが文脈に合わない場所
- [tab](./tab/index.md) との違い: tabは同一階層内でコンテンツを切り替える用途に使用します。breadcrumbは階層をまたいだページ移動を表示し、tabは同一階層内での切り替えに使用します
- **link** との違い: linkは個別のテキストリンクとして単体で使用します。breadcrumbは複数の階層パスを連続して表示するためのまとまりとして使用します

## バリアントプロパティ
| プロパティ | 値 |
|---|---|
| state | `default` / `hover` / `focus` / `active` / `current` |

## コンテンツルール
- 各項目のラベルには、対応するページの正式名称を使用します
- ラベルのテキストは折り返しを生じさせないよう、簡潔に記述します
- 最末尾の現在ページ項目はリンクとして機能させません
- セパレーターはコンテンツではないため、読み上げの対象から除外します

## Do
- 階層の深いページで現在地を示すために使う
- 各項目のラベルにはページの正式名称を使う

## Don't
- 1階層のみのページで使わない
- モーダルやダイアログ内で使わない
