# テキストフィールド

text-field は、ユーザーが1行のテキストを入力・編集するためのコンポーネントです。フォーム上で名前・キーワード・数値などの短いテキストを受け取る場面に使用します。

## 使いどころと選び方

### 使うべきシーン
- 名前・メールアドレス・検索キーワードなど、1行で収まるテキストを入力してもらうとき
- フォームの入力項目として使用するとき

### 使わないほうがよいシーン
- 複数行にわたる長文を入力してもらう場合は、[text-area](./text-area.md) を使用します
- あらかじめ決まった選択肢から選ばせる場合は、[select-box](./select-box/index.md) または [radio-button](./radio-button/index.md) などを使用します

### 他コンポーネントとの違い・使い分け
- text-field は入力欄のみを提供するコンポーネントです。ラベルや必須バッジ、補足テキストと組み合わせて使用したい場合は、text-field-unit を使用します。text-field-unit は label-unit と text-field をひとまとまりにしたコンポーネントで、フォームの1項目をまとめて表現できます

## 構成とルール

### バリエーション・状態

| プロパティ | 値 |
|---|---|
| viewport | `desktop` / `phone` |
| size | `medium` / `large` |
| state | `default` / `hover` / `focus` / `error` / `error-hover` / `error-focus` / `disabled` |

#### viewport（表示環境）
- `desktop`：デスクトップ向けのレイアウトで表示されます
- `phone`：スマートフォン向けにレイアウトが調整されます

#### size（サイズ）
- `medium`：標準サイズです
- `large`：やや大きなサイズです。視覚的な存在感を高めたい場面や、タッチ操作が主なスマートフォン向けフォームに適しています

#### state（状態）
- `default`：通常の入力待ち状態です
- `hover`：マウスポインターが乗っている状態です
- `focus`：フォーカスが当たっている状態です
- `error`：入力値にエラーがある状態です。入力域の下にエラーメッセージが表示されます
- `error-hover`：エラー状態でマウスポインターが乗っている状態です
- `error-focus`：エラー状態でフォーカスが当たっている状態です
- `disabled`：操作不能な状態です。入力は受け付けません

### コンテンツルール
- プレースホルダーは入力内容の期待値を端的に示す文言にします（例：「田中 太郎」「example@email.com」）
- エラーメッセージは何がどう誤っているかを端的に伝える文言にします。ユーザーがとるべき修正アクションが明確になるよう、です・ます調の丁寧語で記載します
- 1つの入力欄に表示するエラーメッセージは1件にします

### text-field-unit の構成
text-field-unit は label-unit と text-field を縦に積み重ねたコンポーネントです。label-unit はフィールドの上部に表示され、以下の要素を持ちます。
- ラベルテキスト（text）：フィールドの入力項目名を表示します
- 必須バッジ（required）：必須項目であることを視覚的に示します
- 補足テキスト（support-text）：ラベルの隣に補足説明を追加できます。show-support-text を true にすると表示されます

## 振る舞い
- クリック・タップするとフォーカスが当たり、キーボードによる文字入力が可能になります
- フォーカス中（focus 状態）は入力域の輪郭が変化し、フォーカスを視覚的に示します
- フォーカスが外れると default 状態に戻ります。ただし、エラーがある場合は error 状態を維持します
- Tab キーでフォーカスを移動できます
- disabled 状態では、クリック・タップおよびキーボード操作のいずれによっても入力を受け付けません

## 役割と目的
- プレースホルダーで入力内容のヒントを示します
- エラー状態ではエラーメッセージを表示し、入力誤りをユーザーに伝えます
- text-field-unit と組み合わせることで、ラベルや必須バッジ、補足テキストを伴った入力フィールドとして使用できます
