# テーブル

table は、構造化されたデータを行と列の形式で一覧表示するためのコンポーネントです。

## 使いどころと選び方

### 使うべきシーン
- 企業一覧、財務諸表、業績予想など、複数の属性を持つ項目を一覧で比較したいとき
- 並べ替えやフィルタリングなど、データ操作の起点となる画面を作るとき
- 行数・列数が多く、スキャン性を確保するためにグリッド構造が必要なとき

### 使わないほうがよいシーン
- 単一項目の詳細情報を表示するだけの場合（詳細ページや説明文など）
- 選択肢の提示や入力フォームとして使いたい場合（List や Form コンポーネントを検討する）
- データ件数がごく少なく、比較の必要がない場合

### 他コンポーネントとの違い・使い分け
- **List**: 項目の並び・一覧表示が目的で、属性の比較が不要な場合は List を使います。Table は列の比較が前提のレイアウトです
- **Card**: 視覚的なサムネイルや画像を伴う一覧には Card が適します。Table はテキスト・数値データの整理に向いています

## 構成とルール

table は、table-header-cell（ヘッダー行のセル）と table-body-cell（ボディ行のセル）という 2 種類のセルコンポーネントで構成されます。

### バリエーション・状態

#### view（ビュー）
table には 2 種類のビューがあります。
- `grid`：罫線（セルを区切る線）で各セルが明確に区切られる、情報密度の高い表示です
- `list`：縦罫線を省いた軽量な表示です。一覧・閲覧を主体にする場合に向きます

#### 行の状態（state）
- `default`：通常表示
- `hover`：カーソルが行上にあるときの強調表示。どの行を見ているかを視覚的に補助する目的で使います

#### セルの種類（content-type）
| 種類 | 説明 | kit |
|------|------|-----|
| **text** | 文字（リンクにもできる） | `<td>`（リンクは中に `<a>`） |
| **number** | 数値（右寄せ・等幅数字） | `.mi-table__num` |
| **header** | 行見出し（太字） | `.mi-table__row-header`（`<th scope="row">`） |
| **checkbox** | 行選択（ヘッダー＝全選択 / 行＝選択） | `.mi-table__check`（中に `.mi-checkbox`） |
| **icon-button** | 行アクション（kebab 等） | `.mi-table__actions`（中に icon-button） |
| **slot** | 任意要素（tag・link-tag・icon 等） | `<td>` に直接置く |
| **empty** | 値が無いセル | 素の `<td></td>`（プレースホルダ記号は無し） |

### コンテンツルール
- table-header-cell・table-body-cell それぞれのルールは各セルコンポーネントを参照します

## 振る舞い

### 行の hover
行にカーソルを合わせると、その行全体の背景色が変化します。列数が多い・行間が詰まっているテーブルで、ユーザーが今どの行を見ているかを視覚的に補助します。

### 縦スクロール
原則として、table はページ全体でスクロールさせ、ヘッダー行はページに対して固定表示（sticky）します。ページ内に複数の table が存在し、それぞれのスクロールが長くなりすぎてページの全体感が掴めない場合に限り、table を独立したスクロール領域として扱うことを許容します。その場合も、目次などの代替手段でページの全体感を補う設計を検討します。

### ソート（並べ替え）
ヘッダーセルに sort を有効にすると、クリックで昇順・降順・デフォルトの順に sortState が切り替わります。並べ替えが有効な列のヘッダーには、現在のソート状態を示すアイコンが表示されます。

### リンクセルのクリック
`text-link: true` の table-body-cell では、テキスト文字列のみがクリック可能なリンクエリアとなります。

## 役割と目的
- 複数の項目を属性ごとに比較・閲覧しやすくする
- データの一覧・検索・絞り込みの起点となる UI として機能する
- ユーザーが多くの情報を効率よくスキャンできるよう、行・列のグリッド構造で情報を整理する
