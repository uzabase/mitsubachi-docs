# user-message

user-message は、AIとの会話（チャット）において、ユーザーが入力・送信した発話内容を表示するコンポーネントです。

## 使いどころと選び方

### 使うべきシーン
- floating-ai-chat（フローティング形式のAIチャットUI）や [ai-chat](./ai-chat.md) の会話ログにおいて、ユーザーが送信したメッセージを表示する場合に使います
- ユーザーが長文を送信した際に、コンパクトに折りたたんで表示したいシーンに適しています

### 使わないほうがよいシーン
- AIからの応答メッセージを表示する場合は、別途用意されたAI応答用のコンポーネントを使います
- 一般的なフォームやコメント欄など、チャットコンテキスト以外での使用には適しません

### 他コンポーネントとの違い・使い分け
- AI応答メッセージ用のコンポーネントとは、表示スタイルや配置方向が異なります。user-message はユーザー発言を示すためのコンポーネントです

## 構成とルール

### バリエーション・状態

user-message には `status` プロパティによって3つの状態があります。
- `default`**（デフォルト）**: **テキスト量が10行以下の少ない場合**に、折りたたむ必要がない通常の表示状態です。テキストエリアのみを表示します
- `collapsed`**（折りたたみ）**: **テキストが11行以上の多い場合**に、一部を非表示にして折りたたんだ状態です。テキストエリアの末尾にグラデーションのオーバーレイが重なり、「すべて表示」ボタンが表示されます
- `expanded`**（展開）**: collapsed 状態からユーザーが展開した状態です。テキスト全文が表示され、「表示を減らす」ボタンが表示されます

### コンテンツルール
- テキストエリアには、ユーザーが送信したメッセージをそのまま表示します。**改変や要約は行いません。**
- 「すべて表示」「表示を減らす」というボタンラベルは固定の文言です。ラベルは変更しません
- 「すべて表示」ボタンには chevron-down（下向き山形）のアイコンが付きます
- テキストエリアは角丸のある背景色付きのコンテナです。テキストの周囲には適切な余白があります

## 振る舞い
- **collapsed 状態**では、テキストエリアの末尾にグラデーションのオーバーレイが表示され、続きがあることをユーザーに示します。「すべて表示」ボタンをタップ・クリックすると、expanded 状態に遷移します
- **expanded 状態**では、テキスト全文が表示されます。「表示を減らす」ボタンをタップ・クリックすると、collapsed 状態に戻ります
- **default 状態**は、テキスト量が折りたたみを必要としない場合の状態であり、トグル操作は発生しません
- キーボード操作では、「すべて表示」「表示を減らす」のボタンにフォーカスを当て、Enter キーまたは Space キーで操作できます

## 役割と目的
user-message は、AIとの会話（チャット）において、ユーザーが入力・送信した発話内容を表示するコンポーネントです。
- AIとの会話において、ユーザー側の発言を視覚的に区別して表示するという課題を解決します
- チャット画面上でユーザーの送信メッセージを一貫したスタイルで示すという、UI上の基本的な役割を担います
- ユーザーは自分が送信した内容をひとめで確認でき、文字量が多い場合は折りたたんで簡潔に表示することで、画面の視認性を保ちます
