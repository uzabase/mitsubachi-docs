# tag

情報にラベルを付けて分類・識別するためのコンポーネント群。

> mockup で再現する場合は `mockup/mitsubachi-mockup.css` の `.mi-tag`（クリック可能は `.mi-link-tag`） を使う（自作しない）。

## 使い分け

| コンポーネント | 用途 |
|---|---|
| [read-only-tag](./read-only-tag.md) | 情報の分類や属性、状態を示す表示専用ラベル |
| [link-tag](./link-tag.md) | クリック可能なナビゲーションリンク型タグ |
| [link-tag-group](./link-tag-group.md) | 複数のlink-tagをまとめて表示するコンテナ |
