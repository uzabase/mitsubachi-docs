# read-only-tag

read-only-tag は、情報の分類や属性、状態を示すための表示専用コンポーネントです。ユーザーの操作はできず、ラベルとして情報を補足・整理する目的で使用されます。

## いつ使うか

- コンテンツの状態（ポジティブ・ネガティブ・情報・中立）を意味的な色分けで示したい場合
- クリック操作が不要なシンプルな情報ラベルとして利用する場合

## いつ使わないか

- タグをクリックして関連コンテンツへ遷移させたい場合（→ [link-tag](./link-tag.md) を使います）
- **[link-tag](./link-tag.md) との違い**: read-only-tag はクリック不可の表示専用ラベルです。ナビゲーション機能が不要で情報を補足・整理するのみの目的に使います。また neutral / information / positive / negative のバリアントを持ち、意味的な色分けで情報を伝えます。link-tag は色の意味分けを持ちません。

## バリアントプロパティ

| プロパティ | 値 | 説明 |
|---|---|---|
| variant | neutral / information / positive / negative | 色による意味分け |

### variant（種類）
- `neutral`: 中立。特定の意味を持たない一般的なラベルに使います。
- `information`: 情報。ユーザーに参考情報や補足説明を伝える際に使います。
- `positive`: ポジティブ。良好・完了・成功などを表す際に使います。
- `negative`: ネガティブ。エラー・警告・失敗などを表す際に使います。

## コンテンツルール

- テキストを必ず含みます。
- アイコンはオプションで表示・非表示を切り替えられます（show-icon）。アイコンを使用する場合は、バリアントの意味を補強するアイコンを選択します。
- 色の違いだけでなくテキスト（およびアイコン）でも意味を伝えます。

## Do

- コンテンツの状態や分類を意味的な色分けで示す場面で使う
- 色の違いだけでなくテキスト（およびアイコン）でも意味を伝える
- バリアントの意味を補強するアイコンを選択する

## Don't

- タグをクリックして関連コンテンツへ遷移させたい場面で使わない → [link-tag](./link-tag.md) を使う
- 色の違いだけに依存して意味を伝えない
