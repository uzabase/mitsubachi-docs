# label-unit

label-unit は、フォーム上の入力欄や選択肢が「何を入力・選択するためのものか」を明確に伝えるためのコンポーネントです。ラベルテキスト、必須バッジ、補足テキストをまとめて表示します。

## 使いどころと選び方

### 使うべきシーン
- フォーム内の入力欄や選択肢グループに対して、ラベルを表示するとき
- 必須項目であることを明示したいとき
- 入力内容に関する補足情報（入力形式や制約など）をラベルの近くに表示したいとき

### 使わないほうがよいシーン
- label-unit を単体でUIに配置することは想定していません。text-field、textarea、checkbox-group、radio-button-group などのフォームコンポーネントを通じて使用します

### 他コンポーネントとの違い・使い分け
label-unit はラベルを表示する責務のみを持ち、入力欄そのものは持ちません。実際のフォーム項目を構成する際は、以下のように他コンポーネントと組み合わせて使用します。

| コンポーネント | 説明 |
|---|---|
| text-field | 1行テキスト入力欄と label-unit をセットにしたコンポーネント |
| textarea | 複数行テキスト入力欄と label-unit をセットにしたコンポーネント |
| checkbox-group | チェックボックスグループと label-unit をセットにしたコンポーネント |
| radio-button-group | ラジオボタングループと label-unit をセットにしたコンポーネント |

## 構成とルール

### バリエーション・状態

label-unit は以下のプロパティによって表示が変化します。

| プロパティ | 値 |
|---|---|
| required | `true` / `false` |
| show-support-text | `true` / `false` |

#### required（必須バッジの表示）
- `true`：「必須」バッジを表示します。入力が必須の項目にのみ適用します
- `false`（デフォルト）：必須バッジを表示しません

#### show-support-text（補足テキストの表示）
- `true`：補足テキストを表示します
- `false`（デフォルト）：補足テキストを表示しません

### コンテンツルール
- ラベルテキスト（text）は、入力項目の名称を簡潔に示す文言にします。ユーザーが何を入力・選択するかが一目でわかる言葉を選びます
- 必須バッジは、入力が必須の項目にのみ表示します。任意項目には表示しません
- 補足テキスト（support-text）は、入力形式の説明や制約など、入力を助ける補足情報を入れます。必要な場合のみ表示し、簡潔な内容にとどめます

## 振る舞い
label-unit 自体はインタラクション（クリック・タップなど）を持ちません。ただし、ラベルテキストをクリック・タップした場合、関連する入力欄にフォーカスが移動します（親コンポーネント側の実装に依存します）。

## Do
- 入力項目の名称を簡潔に示すラベルを付ける
- 必須項目には必須バッジを表示する

## Don't
- label-unit を単体でUIに配置しない
- プレースホルダーをラベルの代わりにしない

## 役割と目的
- ラベルテキストによって入力内容の意味を明確にし、ユーザーが迷わず操作できるようにします
- 必要に応じて、入力に関する補足テキストをラベルとあわせて表示します
- 入力必須項目であることを「必須」バッジで明示します
