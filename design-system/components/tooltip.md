# tooltip

tooltip（ツールチップ）は、UI要素に関する補足情報や説明を一時的に表示するコンポーネントです。アイコンやボタンなど、テキストラベルが省略されている要素にカーソルを合わせる（ホバーする）ことで表示され、ユーザーの操作を妨げずに理解を助けます。

## いつ使うか
- [icon-button](./button/icon-button.md)（テキストラベルを持たないアイコンのみのボタン）に付けて、操作の意味を補完するとき。icon-buttonには**必ずtooltipを付ける**こと
- テーブルのヘッダーや略称など、意味が一目ではわかりにくい項目に短い説明を添えるとき
- ホバーで追加情報を見せることで、画面をすっきりと保ちたいとき

## いつ使わないか
- 操作の実行に**必須の情報**を伝えたいとき（ユーザーがホバーしない限り見えないため、見落とされるリスクがある）
- フォームのエラーメッセージやバリデーションの説明に使うとき（エラー専用のコンポーネントを使うこと）
- 長い説明文が必要なとき（テキストが折り返してもmax-widthを超えるような長い内容には向かない。popoverなどの検討を推奨）
- モバイルなど、ホバーが使えない環境が主なとき
- tooltipは**補足的な情報**を短く提示するためのコンポーネントです。操作の起点となるコンポーネントと組み合わせて使います
- **popover**（未定義）：tooltipより多くの情報や、ボタン・リンクなどの操作要素を含める場合はpopoverを使います。tooltipはテキストのみです
- [banner](./banner.md) / [inline-notification](./inline-notification.md)：重要度が高く、ユーザーに必ず見せたい情報にはこちらを使います。tooltipはあくまで補足であり、ユーザーが意図して操作しないと表示されません

## バリアントプロパティ
| プロパティ | 値 |
|---|---|
| (なし) | tooltipはバリエーションや状態の切り替えを持ちません。スタイルは1種類のみです |

## 配置と挙動（Figma node 6656-2364 の仕様）

| 項目 | 値 |
|---|---|
| トリガーからの距離 | **8px**（トリガー（例: icon-button）の**ターゲットエリア**の端から。ghost の icon-button なら 24/32/40px の枠から 8px） |
| 配置方向 | 下（left / center / right 揃え）・上（同）・左横・右横 の8通り。**他の要素を覆わない方向**を選ぶ |
| 最大幅 | **200px**。超えるテキストは折り返す（省略しない） |
| 表示までの遅延 | **0.2s** |
| 消えるまで | **0s**（即時） |
| アニメーション | **ease-out** |
| z-index | すべての要素の**最上位**。他のどの要素にも隠れない |

## コンテンツルール
- テキストは**短く簡潔に**まとめます。一文以内が理想です
- max-widthが設定されており、それを超えるテキストは自動で折り返されます。テキスト部分はmax-widthから左右の内側余白を除いた幅が上限となります
- テキストが長すぎる場合は内容を見直すか、popoverへの切り替えを検討します
- アイコンや画像など、テキスト以外の要素は使用できません

## Do
- [icon-button](./button/icon-button.md) には必ず tooltip を付ける
- 他のUI要素を覆わない方向に配置する
- テキストは短く簡潔にまとめる

## Don't
- 操作に必須の情報を tooltip に頼らない
- 近接する他のUI要素の上に重ねて表示しない
- フォームのエラーメッセージに使わない
- 長い説明文を tooltip で表示しない
