# radio-button-card

radio-button-card は、ラジオボタンとカード型のラベルエリアを組み合わせた、選択肢の1ユニットを表すコンポーネントです。ラベルに加えてサポートテキスト（補足情報）を表示でき、選択肢の内容や違いを視覚的にわかりやすく伝えます。

## 使いどころと選び方

### 使うべきシーン
- 選択肢の内容や違いを補足説明とともに視覚的に伝えたい場合に使います。
- 通常は [radio-button-card-group](./radio-button-card-group.md) の内部部品として配置します。単体で直接UIに配置する場合は、グループのコンテキスト（同一グループ内での排他的選択）が確保されているか確認します。

### 使わないほうがよいシーン
- 補足説明が不要でラベルのみで十分な場合は、radio-button-text を使います。
- 同時に複数の選択肢を選べるようにしたい場合は、[checkbox](../checkbox/index.md) 系のコンポーネントを使います。

### 他コンポーネントとの違い・使い分け
- **radio-button-text との違い**：radio-button-text はラベルのみを表示するシンプルな形式です。radio-button-card はカード型でサポートテキストも表示でき、各選択肢の詳細な説明が必要な場合に適しています。

## 構成とルール

### バリエーション・状態

| プロパティ | 値 |
|---|---|
| selected | `false` / `true` |
| state | `default` / `hover` / `active` / `focus` / `disabled` |
| viewport | `desktop` / `phone` |

#### selected（選択状態）
- `false`：未選択。白い背景とやや濃いボーダーで表示されます。
- `true`：選択済み。淡い青色の背景と薄いボーダーで表示されます。

#### state（インタラクション状態）
- `default`：通常の状態。
- `hover`：マウスカーソルが重なっている状態。オーバーレイで視覚フィードバックを表示します。
- `active`：クリック・タップ中の状態。
- `focus`：フォーカスされている状態。フォーカスリングで視覚化します。
- `disabled`：操作不可の状態。グレーアウトで表示されます。

#### viewport（表示環境）
- `desktop`：デスクトップ向けのテキストサイズで表示します。
- `phone`：スマートフォン向けのテキストサイズ（やや大きめ）で表示します。

### コンテンツルール
- ラベル（選択肢名）は、選択肢の内容が明確に伝わる簡潔な表現にします。
- サポートテキストは選択肢の補足説明や特徴を簡潔に記述します。内容が長くなるとカードの高さが増え、横並びのレイアウトでは列の高さがそろわなくなるため、できるだけ簡潔にまとめます。
- disabled 状態のカードには、操作不可の理由が必要な場合はサポートテキストで補足します。

## 振る舞い
- カード全体をクリック・タップすると選択状態に切り替わり、背景色とボーダー色が変化します。
- グループ内の選択は排他的で、常に1つのカードだけが選ばれます。他の選択肢を選ぶと、前の選択は自動的に解除されます。
- `focus` 状態ではフォーカスリングが表示されます。
- `disabled` 状態ではクリック・タップ操作を受け付けません。

## Do

- カードのラベルは選択肢の内容が明確に伝わる簡潔な表現にする
- サポートテキストは簡潔にまとめる

## Don't

- 補足説明が不要な場面でカード型を使わない → radio-button-text を使う
- サポートテキストを長くしすぎない（カードの高さが増え、横並びで列の高さがそろわなくなる）

## 役割と目的
radio-button-card は、ラジオボタンとカード型のラベルエリアを組み合わせた、選択肢の1ユニットを表すコンポーネントです。
- ラベルに加えてサポートテキスト（補足情報：選択肢の内容や特徴を補足するテキスト）を表示でき、選択肢の内容や違いを視覚的にわかりやすく伝えます。
- 複数の選択肢から1つだけを選ぶ場面で使用し、通常は [radio-button-card-group](./radio-button-card-group.md) の内部部品として機能します。
- 選択状態とインタラクション状態に応じた視覚フィードバックを提供し、ユーザーに現在の選択を明確に伝えます。
