# floating-button

画面上に常に浮かぶように配置される円形のボタンコンポーネントです。ページ内でもっとも重要な主要アクションを促す役割を担います。

## いつ使うか

- ページを問わず常にアクセスしてほしい主要アクションが1つある場合
- スクロールが発生するコンテンツ上で、アクションボタンが画面外に消えてしまうことを防ぎたい場合

## いつ使わないか

- 主要アクションが複数ある場合（floating-button は単一アクションを想定）
- ページに固定のヘッダーやフッターにアクションボタンを配置できる場合
- コンテンツの閲覧を妨げる可能性が高い場合
- コンテンツのフロー内に配置するボタン → [neutral-button](./neutral-button.md)
- 他のUI要素と並べて配置する場合 → [icon-button](./icon-button.md)

| プロパティ | 値 | 説明 |
|-----------|-----|------|
| state | default / hover / active / focus / loading | インタラクション状態 |

## コンテンツルール

- アイコンのみで構成する。テキストラベルは持たない
- 表示するアイコンは固定。任意のアイコンへの差し替えはできない
- loading 状態では、アイコンの代わりに loading コンポーネントが自動的に表示される
- `aria-label` を必ず付ける

## Do

- スクロールしても消えない必要がある主要アクションに使う
- 1ページに1つだけ配置する
- 必ず `aria-label` を付ける

## Don't

- 複数の floating-button を同一ページに配置しない
- コンテンツの閲覧を妨げる位置に配置しない
- ヘッダーやフッターにアクションボタンを配置できる場合に使わない
- アイコンを差し替えない — 固定アイコンのみ使用
