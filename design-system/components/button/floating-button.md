# floating-button

floating-button は、画面上に常に浮かぶように配置される円形のボタンコンポーネントです。ページ内でもっとも重要な主要アクションを促す役割を担います。

## 使いどころと選び方

### 使うべきシーン
- ページを問わず常にアクセスしてほしい主要アクションが1つある場合
- スクロールが発生するコンテンツ上で、アクションボタンが画面外に消えてしまうことを防ぎたい場合

### 使わないほうがよいシーン
- 主要アクションが複数ある場合（floating-button は単一アクションを想定しています）
- ページに固定のヘッダーやフッターにアクションボタンを配置できる場合
- コンテンツの閲覧を妨げる可能性が高い場合

### 他コンポーネントとの違い・使い分け
- **[neutral-button](./neutral-button.md) との違い**: neutral-button はコンテンツのフローの中に配置しますが、floating-button は画面に常時浮かんで表示されます。スクロールしても消えない必要があるアクションに使います
- **[icon-button](./icon-button.md) との違い**: icon-button は他のUI要素と並べて配置しますが、floating-button は独立して画面に固定されます

## 構成とルール

### バリエーション・状態

| プロパティ | 値 |
|---|---|
| state | `default` / `hover` / `active` / `focus` / `loading` |

#### state
- `default`: 通常の表示状態です。アイコンとボーダー・シャドウが表示されます
- `hover`: マウスカーソルが乗ったときの状態です
- `active`: クリック・タップ中の状態です
- `focus`: キーボードフォーカスが当たっている状態です。フォーカスリングが表示されます
- `loading`: アクション実行中の状態です。アイコンの代わりに loading コンポーネントが表示されます

### コンテンツルール
- floating-button はアイコンのみで構成されます。テキストラベルは持ちません
- 表示するアイコンは固定です。任意のアイコンへの差し替えはできません
- loading 状態では、アイコンの代わりに loading コンポーネントが自動的に表示されます
- `aria-label` を必ず付ける

## 振る舞い
- **クリック／タップ時**: active 状態を経てアクションを実行します。処理中は loading 状態に遷移します
- **ホバー時**: hover 状態に遷移し、インタラクティブであることを視覚的にフィードバックします
- **フォーカス時**: フォーカスリングを表示し、キーボード操作での位置を明示します。`Enter` キーまたは `Space` キーでアクションを実行します
- **loading 状態**: アクション実行中はボタンの操作を受け付けません。処理が完了すると default 状態に戻ります
- **配置**: 画面に対して固定（fixed）で配置されます。スクロールしても常に同じ位置に表示され続けます

## Do

- スクロールしても消えない必要がある主要アクションに使う
- 1ページに1つだけ配置する
- 必ず `aria-label` を付ける

## Don't

- 複数の floating-button を同一ページに配置しない
- コンテンツの閲覧を妨げる位置に配置しない
- ヘッダーやフッターにアクションボタンを配置できる場合に使わない
- アイコンを差し替えない — 固定アイコンのみ使用

## 役割と目的
- **解決する課題**: スクロールや画面遷移にかかわらず、主要アクションへのアクセスを常に確保します
- **UI上での基本的な役割**: プロダクト全体で一貫した主要操作のエントリーポイントを提供します
- **ユーザーにとっての意味**: 「今すぐできる重要なアクション」が常に視界に入ることで、迷わず操作できます
