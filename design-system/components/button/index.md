# button

button は、ユーザーがクリック（またはタップ）することでアクションを実行するための、プロダクト内における操作の基本単位です。

## 使いどころと選び方

button は以下の種類があります。

| コンポーネント | 概要 | いつ使うか |
|---|---|---|
| [neutral-button](./neutral-button.md) | 汎用の標準ボタン。特定の意味を持たない一般的な操作に使います | 汎用的なアクション（送信・保存など） |
| [danger-button](./danger-button.md) | 削除・リセットなど破壊的操作に使う警告ボタンです | 削除・リセットなど破壊的操作 |
| [ai-button](./ai-button.md) | AI生成・提案など、生成系AIの実行に限定するボタンです | AI生成・提案・補完の実行 |
| [icon-button](./icon-button.md) | アイコンのみで操作を表現するコンパクトなボタンです | アイコンのみで操作を表現したい |
| [menu-button](./menu-button.md) | クリックでメニューを展開し、複数の操作を提示するボタンです | クリックで複数の操作を提示したい |
| [floating-button](./floating-button.md) | 画面に常時浮かんで表示される、主要アクション用の円形ボタンです | 常時表示する主要アクション |

### 使うべきシーン
- ユーザーにアクションを起点として促す操作が必要な場面全般
- フォームの送信・保存・確認、データの削除、AIの実行、メニューの展開など

### 使わないほうがよいシーン
- リンクとして機能する文脈（ページ遷移のみを目的とする場合は、リンクテキストを使います）
- トグルやフィルターの選択状態を主目的とする場合（状態の保持が主目的の場合は、チェックボックスやタブなど専用コンポーネントを検討します）

## 構成とルール

### バリエーション・状態

ほとんどのサブコンポーネントで共通して提供される状態（state）は以下のとおりです。

| プロパティ | 値 |
|---|---|
| state | `default` / `hover` / `active` / `focus` / `loading` / `disabled` |

- `default`: 通常の表示状態です
- `hover`: マウスカーソルが乗ったときの状態です
- `active`: クリック・タップ中の状態です
- `focus`: キーボードフォーカスが当たっている状態です。フォーカスリングが表示されます
- `loading`: 処理実行中の状態です。loading コンポーネントが表示されます
- `disabled`: 操作不能な状態です

variant（重要度・強調度）と size（大きさ）はサブコンポーネントによって異なります。詳細は各コンポーネントのドキュメントを参照してください。

### コンテンツルール
- テキストラベルを持つボタン（neutral-button・danger-button・ai-button・menu-button）では、ラベルはアクションの内容を端的に表す動詞句で記述します（例：「保存する」「削除する」「AI生成する」）
- テキストラベルは1行に収まる長さとします。長い文章はラベルとして使用しません
- アイコンのみの構成にする場合は、neutral-button や danger-button ではなく [icon-button](./icon-button.md) を使います
- loading 状態では、ラベル・アイコンの代わりに loading コンポーネントが自動的に表示されます
- primary を右、secondary を左に配置します。ボタン間隔は 8px とします

## 振る舞い

各サブコンポーネントに共通する基本的な振る舞いは以下のとおりです。

- **クリック／タップ時**: active 状態を経てアクションを実行します。処理を伴う場合は loading 状態に遷移します
- **ホバー時**: hover 状態に遷移し、インタラクティブであることを視覚的にフィードバックします
- **フォーカス時**: フォーカスリングを表示し、キーボード操作での現在位置を明示します。`Enter` キーまたは `Space` キーでアクションを実行します
- **loading 状態**: アクション実行中はボタンの操作を受け付けません。処理が完了すると default 状態に戻ります
- **disabled 状態**: ボタンの操作を受け付けません。操作できない理由をユーザーに伝える手段を別途検討します

## 役割と目的
- **解決する課題**: ユーザーが意図するアクションを明確に起点として提供し、操作の手がかりを与えます
- **UI上での基本的な役割**: 画面内のあらゆるアクションのエントリーポイントとして機能します。アクションの種類・重要度・文脈に応じて、複数のバリエーション（サブコンポーネント）に分かれています
- **ユーザーにとっての意味**: ラベルやアイコンを通じて「何が起きるか」を事前に伝え、安心して操作できる手がかりを提供します
