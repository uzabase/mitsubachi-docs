# chip

フィルタリングや入力済みの値を表示するコンパクトなコンポーネント群。

> mockup で再現する場合は `mockup-kit/mitsubachi-mockup.css` の `.mi-chip` / `.mi-chip-group`（入力済みは `.mi-input-chip`） を使う（自作しない）。

## 使い分け

| コンポーネント | 用途 |
|---|---|
| [input-chip](./input-chip.md) | ユーザーが入力・選択した値を削除可能な形で表示 |
| [filter-chip](./filter-chip.md) | フィルター条件の選択・切り替え |
| [input-chip-group](./input-chip-group.md) | 複数の input-chip をまとめて管理するコンテナ |
| [filter-chip-group-single](./filter-chip-group-single.md) | filter-chip の単一選択グループ |
| [filter-chip-group-multiple](./filter-chip-group-multiple.md) | filter-chip の複数選択グループ |
