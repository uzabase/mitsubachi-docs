# table-header-cell

table-header-cell は、[table](./table.md)（表形式のデータ表示 UI）のヘッダー行を構成する 1 つのセルです。各列の見出しを担い、ユーザーがデータ内容を解釈するためのコンテキストを提供します。

## 使いどころと選び方

### 使うべきシーン
- テーブルの最上行に列名を表示する場合に使います
- ソート機能を提供する列に使います

### 使わないほうがよいシーン
- データ行のセルには [table-body-cell](./table-body-cell.md) を使います
- テーブル構造を持たないリストやトップコンテンツの見出しには使いません

### 他コンポーネントとの違い・使い分け
- **[table-body-cell](./table-body-cell.md) との違い**: table-header-cell は列の意味を定義する見出しです。table-body-cell は実際のデータを表示するセルです。視覚的なスタイル、意味的なロール（`role="columnheader"` vs `role="cell"`）が異なります

## 構成とルール

### バリエーション・状態

#### content-type（コンテンツの種類）
ヘッダーセルが内包する中身の種類を表す軸です。データ行の table-body-cell より種類は限定され、3 種類です。
- `text`: 列名のテキストを表示します。最も一般的なヘッダーです
- `checkbox`: 行の一括選択用チェックボックス（全選択・全解除のための入力要素）を表示します。チェックボックス列の見出し位置に使います
- `icon-button`: アイコンボタン（アイコンのみのボタン）を表示します。アクション列など、見出しテキストを持たない列に使います

配置（左寄せ・右寄せ）は独立した軸ではなく、この content-type と対応するデータ列の性質によって決まります。

#### sort（ソート可否）
その列がソート（並び替え）に対応しているかどうかを表す軸です。
- `true`: ソート可能な列です。ソート状態を示すインジケーター（並び順を示すアイコン）が表示され、クリックやキー操作でソートを切り替えられます
- `false`: ソート不可の列です。インジケーターは表示されず、見出しの表示のみを担います

#### sort-state（ソート状態）
sort が `true` の列で、現在の並び順を表す軸です。3 状態を取ります。
- `default`: 未ソートの状態です。どの方向にも並び替えられていないことを示します
- `ascending`: 昇順（小さい値から大きい値へ）でソート中の状態です
- `descending`: 降順（大きい値から小さい値へ）でソート中の状態です

操作のたびに「default → ascending → descending → default」と循環し、アイコンの形状でその状態を視覚的に伝えます。色だけに依存せず形状で区別するため、色覚特性に左右されずに判別できます。

#### state（インタラクション状態）
ポインター操作に対するフィードバックの状態です。
- `default`: 通常の状態です
- `hover`: マウスオーバー時の状態です。背景が変化し、操作対象であることを示します。主にソート可能な列で、クリックできることを伝えるために機能します

#### last-column（最終列かどうか）
そのセルがテーブルの最終列にあたるかを示します。`true` のとき右端の罫線などが調整され、テーブルの外枠が正しく閉じるようにします。レイアウト整合のための軸で、見出しの意味そのものは変えません。

### コンテンツルール
- 列名は簡潔な名詞句で表現します。動詞文や長文の説明文にはしません
- 列名はその列に入るデータを正確に表す内容にします
- ソート機能を持つ場合、アイコンはソート状態の表示に使います

## 振る舞い
- ソート可能な列のヘッダーセルをクリック・タップするとソート状態が切り替わります（ソートなし → 昇順 → 降順 → ソートなし）
- キーボードの Space または Enter キーでソート操作を実行します
- ソート状態の変化はアイコンの変化で視覚的に伝えます

## 役割と目的
- テーブルの各列に何のデータが入るかを示します
- 必要に応じてソート機能を内包します
- table-body-cell と組み合わせることで、テーブル全体の意味構造が成立します
