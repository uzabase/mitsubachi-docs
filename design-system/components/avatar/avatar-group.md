# avatar-group

複数のユーザーやメンバーをまとめて視覚的に表現するためのコンポーネントです。[avatar](./avatar.md) を横方向に重ね合わせて（スタック）配置し、グループやチームの存在を一目で伝えます。

## いつ使うか

- タスク・プロジェクト・ドキュメントなどに「担当者」「メンバー」「閲覧者」を表示するとき
- チームや組織に属するユーザーを一覧の行内やカード内にコンパクトに示すとき
- 人数が複数（2名以上）であり、全員を個別に表示するスペースが確保できないとき

## いつ使わないか

- 表示するメンバーが1名のみの場合 → [avatar](./avatar.md) を単体で使う
- メンバー一覧を詳細情報（氏名・役職など）とともに示す必要がある場合 → リストや専用のメンバーパネルを検討する

## バリアントプロパティ

| プロパティ | 値 |
|---|---|
| size | small / medium / large / x-large / 2x-large |
| item | 1〜5 |
| max-item | 5 |

## コンテンツルール

- 内部の avatar はテキスト（variant: text）形式のみ使用する
- テキストは1文字を基本とする（複数文字は幅オーバーフローの原因になる場合がある）
- アバターの順序は表示上の意味（参加日順、ロール順など）に応じて実装側で制御する
- グループ内のカラーはメンバーごとに一意となるよう設定することを推奨する
- 表示件数が max-item を超えるデータがある場合、超過分の表示方法は実装側で制御する

## Do

- 重なり幅はアバターのサイズの4分の1とする
- スタック時は各アバターに境界線（1px のストローク）を付ける
- 2名以上のメンバーを表示するときに使う

## Don't

- 1名のみの表示に使わない → [avatar](./avatar.md) を使う
- avatar 単体にストロークを付けない（avatar-group 内でのみストロークを使用する）
