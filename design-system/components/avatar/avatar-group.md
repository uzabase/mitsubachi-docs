# avatar-group

複数のユーザーやメンバーをまとめて視覚的に表現するためのコンポーネントです。[avatar](./avatar.md) を横方向に重ね合わせて（スタック）配置し、グループやチームの存在を一目で伝えます。

## 使いどころと選び方

### 使うべきシーン
- タスク・プロジェクト・ドキュメントなどに「担当者」「メンバー」「閲覧者」を表示するとき
- チームや組織に属するユーザーを一覧の行内やカード内にコンパクトに示すとき
- 人数が複数（2名以上）であり、全員を個別に表示するスペースが確保できないとき

### 使わないほうがよいシーン
- 表示するメンバーが1名のみの場合は、avatar-group ではなく [avatar](./avatar.md) を単体で使う
- メンバー一覧を詳細情報（氏名・役職など）とともに示す必要がある場合は、リストや専用のメンバーパネルなど別のコンポーネントを検討する
- アバターに対してクリックやホバーで個別のアクションを提供しない、純粋な装飾目的の用途には使わない

### 他コンポーネントとの違い・使い分け
- **[avatar](./avatar.md) との違い**: avatar は1名を表示する単体コンポーネントです。avatar-group は複数の avatar をスタック表示するラッパーであり、「グループ」という文脈を持ちます。1名のみの場合は avatar を使います
- **判断の観点**: 表示するユーザーが2名以上かどうか、またグループとしての意味を持たせたいかどうかが選択の基準です

## 構成とルール

avatar-group は、内部に [avatar](./avatar.md) インスタンスを最大5件まで含むコンポーネントです。各 avatar は横方向に重なりながら配置されます。
表示件数（`item`）が max-item（最大5件）を超えるデータがある場合、超過分は avatar-group の視覚的な表現のみで管理され、追加情報の表示方法は実装側で制御します。

### バリエーション・状態

| プロパティ | 値 |
|---|---|
| size | small / medium / large / x-large / 2x-large |
| item | 1〜5 |
| max-item | 5 |

#### サイズ（`size`）
avatar-group は small / medium / large / x-large / 2x-large の5段階のサイズをサポートします。内部の avatar も同じサイズで統一されます。

#### 表示件数（`item`）
1〜5 の範囲で表示する avatar の数を指定します。

#### 最大表示件数（`max-item`）
現在は 5 のみサポートしています。

### コンテンツルール
- 内部の avatar はテキスト（`variant: text`）形式のみ使用します。テキストにはユーザーのイニシャルなどを表示します
- テキストは1文字を基本とします（「TA」のような複数文字は幅オーバーフローの原因になる場合があります）
- アバターの順序は、表示上の意味（例：参加日順、ロール順）に応じて実装側で制御します
- グループ内のカラーはメンバーごとに一意となるよう設定することを推奨します

## 振る舞い

- コンポーネント自体はクリックやフォーカスの挙動を持ちません。インタラクションが必要な場合は、ラッパーとなる親コンポーネント側で制御します
- アバターはスタック（後ろに重なる）形式で横並びに表示されます。視覚的に手前側のアバターが優先して見えます
- 重なり幅はアバターのサイズの4分の1とします（例: 直径40のアバターの場合、重なり部分は10）
- avatar-group 内の avatar の表示順はデザインシステムでは未定義であり、使用箇所ごとに定義します（例: NPコメントなら重要度順、ユーザー一覧なら直近ログイン順）
- スタック時は各アバターに境界線（1px のストローク）を付けます。avatar コンポーネント単体にはストロークはありません

## Do

- 重なり幅はアバターのサイズの4分の1とする
- スタック時は各アバターに境界線（1px のストローク）を付ける
- 2名以上のメンバーを表示するときに使う

## Don't

- 1名のみの表示に使わない → [avatar](./avatar.md) を使う
- avatar 単体にストロークを付けない（avatar-group 内でのみストロークを使用する）
