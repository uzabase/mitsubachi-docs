# avatar

ユーザーを視覚的に識別するためのコンポーネントです。画像・イニシャル・アイコンによって「誰か」という情報を直感的に伝えます。

## 使いどころと選び方

### 使うべきシーン
- ユーザーアカウントを特定・識別したい場面（ヘッダーメニュー、コメント欄、プロフィール画面など）
- 複数ユーザーをまとめて表示したい場面（グループやチームメンバーの一覧）。複数ユーザーの表示には [avatar-group](./avatar-group.md) を利用する

### 使わないほうがよいシーン
- ユーザーと無関係な画像やアイコンを表示したい場合（他のコンポーネントや img 要素などで対応する）
- 複数ユーザーをスタック表示したい場合 → [avatar-group](./avatar-group.md)

### 他コンポーネントとの違い・使い分け
- **avatar**: 単一ユーザーを表示する場合に使います
- [avatar-group](./avatar-group.md): 複数のユーザーをまとめてスタック（重ね合わせ）表示する場合に使います。アバターを横に並べて重ねることで、グループやチームを視覚的に表現します

## 構成とルール

### バリエーション・状態

| プロパティ | 値 |
|---|---|
| variant | image / text / icon |
| size | small / medium / large / x-large / 2x-large |
| color | plum / violet / blue / viridian / green / brown / red（variant=text のみ） |
| inactive | true / false |

#### variant（種類）
アバターの表示内容を3種類から選びます。優先度の高い順に適用します。

| variant | 内容 |
|---------|------|
| **image** | ユーザーが設定した画像を表示します。画像がある場合は最優先で使用します |
| **text** | メールアドレスから生成した2文字のイニシャル（アルファベット大文字）を表示します。画像がない場合のデフォルトです |
| **icon** | ユーザーを特定できない場合、またはエラー等で画像もテキストも表示できない場合に使用します |

#### size（サイズ）
使用箇所に応じて5種類から選びます。

| size | 主な使用箇所 |
|------|-----------|
| **small** | avatar-group（スタートアップ情報リサーチのNPコメントなど） |
| **medium** | ヘッダーメニューなど |
| **large** | アカウントメニューを開いた際のユーザー情報表示 |
| **x-large** | プロフィール画面（デスクトップ） |
| **2x-large** | プロフィール画面（モバイル） |

#### color（背景色） ※ variant=text のときのみ有効
- `variant=text` の場合のみ有効なプロパティです
- plum・violet・blue・viridian・green・brown・red の7色があります。ユーザーが自分で選ぶことはなく、システムがランダムに割り振ります

#### inactive（非活性）
- ユーザーが利用停止・アカウント削除された際に、視覚的に休止・停止状態を表すプロパティです
- 操作不能を示す `disabled` とは目的が異なります。`true` / `false` の2値で切り替えます

### コンテンツルール

#### variant=text のイニシャル生成ルール
- メールアドレスの先頭から2文字のアルファベットを使用します
- 記号・数字は対象外とします
- 大文字で表記します
- 条件を満たすアルファベット2文字が取れない場合は、先頭の文字を最大2文字使用します
  - 例: `taro.yamada@uzabase.com` → **TA** / `9.@uzabase.com` → **9.**

#### variant=image の画像表示ルール
- 画像はアバターのサイズを最小サイズとして扱います
- 推奨サイズより小さい画像が設定された場合も、上下中央配置で引き伸ばして表示します。余白は作りません

## 振る舞い

アバター自体はインタラクティブな操作（クリック・フォーカスなど）を持たず、表示専用のコンポーネントです。ただし、ボタンやリンクと組み合わせて配置する場合は、親コンポーネントの操作仕様に従います。

## Do

- 画像がある場合は必ず image variant を使用する
- 名前やラベルと組み合わせる場合、アバターは左側に配置する
- color は variant=text の場合にシステムがランダムに割り振る

## Don't

- avatar-group 内ではなく単体で複数ユーザーを並べない → [avatar-group](./avatar-group.md) を使う
- ユーザーと無関係な画像表示に使わない

## 役割と目的

- **解決する課題**: ユーザー名や数値だけでは伝わりにくい「誰か」という情報を、画像・イニシャル・アイコンによって直感的に伝えます
- **UI上での基本的な役割**: ヘッダーやコメント、プロフィールなど、ユーザーの存在を示す場面に配置し、アカウントを識別しやすくします
- **ユーザーにとっての意味**: 「このコンテンツは誰が関わっているか」を素早く把握でき、情報の文脈をスムーズに理解できます
