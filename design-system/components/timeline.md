# タイムライン

timeline-item は、出来事や状態の変化を時系列に沿って表示するためのコンポーネントです。複数の timeline-item を組み合わせることで、タイムライン全体を構成します。

## 使いどころと選び方

### 使うべきシーン
- 企業の沿革や、ニュース・イベントの一覧、人物の経歴など、時系列で情報を並べて提示したいとき
- 複数の出来事の前後関係や流れを視覚的に伝えたいとき
- 特定のイベントを強調しながら、前後の出来事と一緒に提示したいとき

### 使わないほうがよいシーン
- 時系列の流れを持たない単なるリスト表示には、[table](./table.md) やリストを使います
- ステップバイステップの操作手順を案内する場合は、stepper コンポーネント（未定義）の使用を検討します

### 他コンポーネントとの違い・使い分け
- **stepper**（未定義）との違い：stepper はユーザーが操作を進める「手順」の案内に使います。timeline-item は過去から現在への「経緯・記録」の表示に使います。操作を伴わない情報提示には timeline が適しています

## 構成とルール

timeline-item は以下の要素で構成されます。

| 要素 | 説明 |
|------|------|
| **ドット（Dot）** | 各アイテムの位置を示すマーカーです。通常はグレー、強調（emphasized）時はアクセントカラーで表示されます |
| **接続線（Flow）** | アイテム間をつなぐ縦線です。group が true のとき、first・middle・last の各ポジションに応じて上下に表示されます |
| **コンテンツ（Slot）** | アイテムの本文エリアです。任意のコンテンツを配置できます |

### バリエーション・状態

#### emphasized（強調）
- `false`（デフォルト）：ドットが通常の色（グレー）で表示されます
- `true`：ドットがアクセントカラーで表示され、そのアイテムを視覚的に強調します

#### group（グループ化）
- `true`（デフォルト）：複数の timeline-item をグループとして並べ、アイテム間を接続線でつなぎます
- `false`：単独のアイテムとして表示します。接続線は表示されません

#### position（位置）
- `first`：タイムラインの先頭アイテムです。上方向の接続線はなく、下方向の接続線のみ表示されます
- `middle`：タイムラインの中間アイテムです。上下両方向に接続線が表示されます
- `last`：タイムラインの末尾アイテムです。上方向の接続線はありますが、下方向の接続線はありません

#### item-spacing（余白）
- `normal`（デフォルト）：アイテム間の余白が標準の広さです
- `loose`：アイテム間の余白が広くなります。情報量が多い場合や読みやすさを重視する場面で使います

### コンテンツルール
- スロット（Slot）には任意のコンテンツを配置できます。コンテンツの種類や形式はタイムラインの用途に応じて設計します
- 1つのアイテムに載せる情報量が多すぎる場合、タイムライン全体の可読性が損なわれるため、表示内容を絞ることを推奨します

## 振る舞い
- timeline-item 自体はインタラクティブな操作（クリック・タップ）を持ちません。操作を伴う場合は、スロット内に配置したコンポーネント（ボタン、リンクなど）を通じて実装します
- group と position の組み合わせにより、接続線の表示が自動的に制御されます。先頭（first）は上の線なし、末尾（last）は下の線なし、中間（middle）は上下両方表示となります
- item-spacing が loose のとき、スロット下部の余白が広くなります

## 役割と目的
- 時間の流れに基づいて情報を並べることで、過去から現在までの経過や、複数のイベントの関係性を直感的に理解できるようにします
- 各アイテムは左側にドット（マーカー）と接続線を持ち、コンテンツ（スロット）部分に任意の情報を表示します
