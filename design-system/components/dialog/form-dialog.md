# form-dialog

ユーザーからの入力を受け付けるフォームをモーダルダイアログ内に提示するコンポーネントです。ページ遷移を行わずに現在のコンテキストを保ちながら、シンプルな入力・編集操作を完結させます。

## いつ使うか

- アイテムの新規追加（リストへの追加、メンバー招待など）
- 名前変更・設定変更など、入力項目が少なく簡潔な編集
- ページ遷移を伴わずモーダル内で完結できるシンプルなタスク

## いつ使わないか

- 入力項目が多く複雑な場合 → 専用の編集ページを設けることを検討する
- フォーム入力を必要としない確認 → [action-dialog](./action-dialog.md) を使う
- 情報の表示のみで入力を伴わない場合 → [information-dialog](./information-dialog.md) を使う

| プロパティ | 値 | 説明 |
|-----------|-----|------|
| width | medium / large | ダイアログの幅 |

## コンテンツルール

| 要素 | 必須 | 説明 |
|------|:----:|------|
| タイトル | 必須 | フォームの目的を示す見出し |
| フォーム要素 | 必須 | text-field、select などの入力コンポーネント。ユースケースに応じて適切な入力要素を組み合わせる |
| 送信ボタン（プライマリ） | 必須 | フォームの内容を確定するためのボタン |
| キャンセルボタン | 必須 | 入力をキャンセルするためのボタン |

**ライティングルール：**
- タイトルは「追加」「編集」など操作内容を示す動詞で始める
- 送信ボタンのラベルは操作内容を示す動詞にする（例：「追加する」「保存する」）
- バリデーションエラーは [inline-notification](../inline-notification.md) またはフォーム要素内のエラー表示で伝える
- キャンセルボタンのラベルは「キャンセル」を基本とする

## Do

- タイトルを操作内容を示す動詞で始める
- 送信ボタンのラベルは操作を示す動詞にする（「追加する」「保存する」）
- 入力項目は少なくシンプルに保つ

## Don't

- 入力項目が多く複雑なフォームをダイアログに詰め込まない → 専用ページを検討する
- アクション確認だけの目的で使わない → [action-dialog](./action-dialog.md) を使う
- 情報通知だけの目的で使わない → [information-dialog](./information-dialog.md) を使う
