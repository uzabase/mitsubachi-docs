# form-dialog

form-dialog は、ユーザーからの入力を受け付けるフォームをモーダルダイアログ（画面全体を覆うオーバーレイ上に表示される対話型パネル）内に提示するコンポーネントです。バックドロップ（半透明の暗幕）で背景UIへの操作をブロックし、ユーザーの注意を入力フォームに集中させます。

## 使いどころと選び方

### 使うべきシーン
- アイテムの新規追加（リストへの追加、メンバー招待など）
- 名前変更・設定変更など、入力項目が少なく簡潔な編集
- ページ遷移を伴わずモーダル内で完結できるシンプルなタスク

### 使わないほうがよいシーン
- 入力項目が多く複雑な場合（→ 専用の編集ページを設けることを検討します）
- フォーム入力を必要としない確認（→ [action-dialog](./action-dialog.md) を使います）
- 情報の表示のみで入力を伴わない場合（→ [information-dialog](./information-dialog.md) を使います）

### 他コンポーネントとの違い・使い分け
- **[action-dialog](./action-dialog.md) との違い**：action-dialog は入力フィールドを持たず、短いテキスト確認のみを目的とします。form-dialog は入力を受け付けます。
- **[information-dialog](./information-dialog.md) との違い**：information-dialog は情報の表示のみを目的とし、入力フィールドを持ちません。

## 構成とルール

### バリエーション・状態
- **width**：`medium`（標準幅）と `large`（幅広）の2種類があります
- フォーム要素のバリデーションエラー状態を持ちます

### コンテンツルール

form-dialog は以下の要素で構成されます。

| 要素 | 必須 | 説明 |
|------|:----:|------|
| タイトル | 必須 | フォームの目的を示す見出し |
| フォーム要素 | 必須 | text-field、select などの入力コンポーネント。ユースケースに応じて適切な入力要素を組み合わせる |
| 送信ボタン（プライマリ） | 必須 | フォームの内容を確定するためのボタン |
| キャンセルボタン | 必須 | 入力をキャンセルするためのボタン |

**ライティングルール：**
- タイトルは「追加」「編集」など操作内容を示す動詞で始めます
- 送信ボタンのラベルは操作内容を示す動詞にします（例：「追加する」「保存する」）
- バリデーションエラーは [inline-notification](../inline-notification.md) またはフォーム要素内のエラー表示で伝えます
- キャンセルボタンのラベルは「キャンセル」を基本とします

## 振る舞い

[dialog](./index.md) の振る舞いは dialog 全体で共通。

## Do

- タイトルを操作内容を示す動詞で始める
- 送信ボタンのラベルは操作を示す動詞にする（「追加する」「保存する」）
- 入力項目は少なくシンプルに保つ

## Don't

- 入力項目が多く複雑なフォームをダイアログに詰め込まない → 専用ページを検討する
- アクション確認だけの目的で使わない → [action-dialog](./action-dialog.md) を使う
- 情報通知だけの目的で使わない → [information-dialog](./information-dialog.md) を使う
