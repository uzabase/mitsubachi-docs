# dialog

dialog は、ユーザーの操作フローを一時的に中断し、確認・情報提供・入力のいずれかを目的とするモーダルダイアログ（画面全体を覆うオーバーレイ上に表示される対話型パネル）です。バックドロップ（半透明の暗幕）で背景UIへの操作をブロックし、ユーザーの注意をダイアログに集中させます。

目的に応じて3種類のサブコンポーネントに分かれています。

| コンポーネント | 目的 |
|---|---|
| [action-dialog](./action-dialog.md) | アクションの実行確認。「実行する」「キャンセルする」の二択をユーザーに求める |
| [form-dialog](./form-dialog.md) | フォーム入力の収集。ページ遷移なしにモーダル上で入力・編集を完結させる |
| [information-dialog](./information-dialog.md) | 情報の提示・通知。アクション選択を求めず、内容の閲覧・確認が目的 |

## 使いどころと選び方

### 使うべきシーン
- ユーザーの注意を強制的に引き付け、操作フローを一時停止させる必要がある場合
- 背景のUIへの誤操作を防ぎながらタスクを完結させる必要がある場合

### 使わないほうがよいシーン
- 短い一時的なフィードバック通知（→ [snackbar](../snackbar.md) を使います）
- ページの文脈に沿った常時表示の通知・警告（→ inline-notification や notification を使います）
- ユーザーの作業フローを中断させずに情報を提示できる場合

### 他コンポーネントとの違い・使い分け
- snackbar：操作に対する短いフィードバックに特化し、自動消去されます。dialog はユーザーが明示的に閉じるまで表示を維持します。
- inline-notification：ページ内に固定表示されます。dialog はページ上に重ねて表示され、背景UIへの操作をブロックします。
- notification：ページレベルの常時表示通知に使います。dialog はユーザーの操作フローを一時停止させる必要がある場合に使います。

#### サブコンポーネントの使い分け

| 判断の観点 | 適切なコンポーネント |
|---|---|
| 「実行する」「キャンセルする」の二択が必要 | action-dialog |
| 情報の提示のみで、アクション選択が不要 | information-dialog |
| ユーザーからの入力・編集が必要 | form-dialog |

## 構成とルール

### 共通の構造

すべての dialog は以下の要素で構成されます。

| 要素 | 必須 | 説明 |
|------|:----:|------|
| **バックドロップ（オーバーレイ）** | 必須 | ダイアログ背後の半透明の暗幕。背景UIへの操作をブロックする |
| **タイトル** | 必須 | ダイアログの目的を端的に示す見出し |
| **説明文** | 任意 | タイトルを補足する詳細情報 |
| **アクションエリア** | 必須 | ボタン類を配置するエリア。サブコンポーネントによって内容が異なる |

### バリエーション・状態

#### width（幅）
- `medium`：標準的な幅。大多数のユースケースに適用します
- `large`：幅広のレイアウト。コンテンツ量が多い場合に使用します

#### 表示位置
画面の上下左右中央に表示します。

### コンテンツルール
- タイトルはダイアログの目的をひと目で理解できる簡潔な文にします

## 振る舞い

### 開く・閉じる操作

| 操作 | 結果 |
|------|------|
| トリガー要素をクリック・タップ | ダイアログが開く |
| バックドロップ（ダイアログ外領域）をクリック | ダイアログが閉じない |
| ESC キーを押下 | ダイアログが閉じる |

#### 重要
- ダイアログを閉じるための close-button は配置してはいけない。
- ダイアログの外側の領域をクリックで、ダイアログを閉じてはいけない。

### フォーカス管理
- **ダイアログが開いたとき**：最初のインタラクティブ要素（閉じるボタン）にフォーカスが移動します
- **ダイアログが開いている間**：フォーカスはダイアログ内に閉じ込められます（フォーカストラップ）。ダイアログ外の要素へのフォーカス移動を防ぎます
- **ダイアログが閉じたとき**：ダイアログを開いたトリガー要素にフォーカスが戻ります

### 背景UIへの操作
- ダイアログ表示中は、バックドロップによって背景UIへの操作を受け付けません
