# action-dialog

ユーザーに対してアクションの実行を確認させるためのモーダルダイアログです。取り消しが困難・影響範囲が大きいアクションを実行前に確認し、誤操作を防ぎます。

## いつ使うか

- データの削除・一括変更など、取り消し不可能・影響範囲が大きいアクションの実行確認
- ユーザーが「実行する」「キャンセルする」のいずれかを明示的に選択すべきシーン

## いつ使わないか

- フォーム入力を伴う操作 → [form-dialog](./form-dialog.md) を使う
- ユーザーへの情報通知のみで、アクション選択が不要な場合 → [information-dialog](./information-dialog.md) を使う
- 軽微な操作結果のフィードバック → [snackbar](../snackbar.md) を使う

## コンテンツルール

| 要素 | 必須 | 説明 |
|------|:----:|------|
| タイトル | 必須 | 実行しようとしているアクションを端的に示す見出し |
| 説明文 | 任意 | タイトルだけでは伝わらないアクションの詳細・影響範囲 |
| プライマリアクションボタン | 必須 | アクションを実行するためのボタン |
| キャンセルボタン | 必須 | アクションをキャンセルするためのボタン |

**ライティングルール：**
- タイトルは動詞を含む短い文で記述する（例：「削除しますか？」「変更を保存しますか？」）
- アクションの影響が大きい場合は説明文を設けて詳細を補足する
- プライマリアクションボタンのラベルは、実行する操作を示す動詞にする（例：「削除する」「保存する」）。「OK」「はい」など曖昧な表現は避ける
- キャンセルボタンのラベルは「キャンセル」を基本とする

## Do

- タイトルに動詞を含め、実行内容を明確にする
- プライマリアクションボタンのラベルは操作を示す動詞にする（「削除する」「保存する」）
- 影響が大きいアクションには説明文を設ける

## Don't

- 「OK」「はい」など曖昧なボタンラベルにしない
- フォーム入力を action-dialog に含めない → [form-dialog](./form-dialog.md) を使う
- 情報通知だけの目的で使わない → [information-dialog](./information-dialog.md) を使う
