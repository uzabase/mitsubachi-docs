# action-dialog

action-dialog は、ユーザーに対してアクションの実行を確認させるためのモーダルダイアログ（画面全体を覆うオーバーレイ上に表示される対話型パネル）です。バックドロップ（半透明の暗幕）で背景UIへの操作をブロックし、ユーザーの注意をダイアログに集中させた上で、明示的な意思決定を促します。

## 使いどころと選び方

### 使うべきシーン
- データの削除・一括変更など、取り消し不可能・影響範囲が大きいアクションの実行確認
- ユーザーが「実行する」「キャンセルする」のいずれかを明示的に選択すべきシーン

### 使わないほうがよいシーン
- フォーム入力を伴う操作（→ [form-dialog](./form-dialog.md) を使います）
- ユーザーへの情報通知のみで、アクション選択が不要な場合（→ [information-dialog](./information-dialog.md) を使います）
- 軽微な操作結果のフィードバック（→ [snackbar](../snackbar.md) を使います）

### 他コンポーネントとの違い・使い分け
- **[information-dialog](./information-dialog.md) との違い**：information-dialog はアクションの選択を求めず、情報の閲覧・確認が目的のダイアログです。action-dialog はプライマリアクションボタンとキャンセルボタンの2ボタン構成が必須です。
- **[form-dialog](./form-dialog.md) との違い**：form-dialog はフォーム入力を伴います。action-dialog は入力フィールドを持たず、アクションの確認のみを目的とします。

## 構成とルール

### バリエーション・状態
- **width**：`medium`（標準幅）と `large`（幅広）の2種類があります

### コンテンツルール

action-dialog は以下の要素で構成されます。

| 要素 | 必須 | 説明 |
|------|:----:|------|
| タイトル | 必須 | 実行しようとしているアクションを端的に示す見出し |
| 説明文 | 任意 | タイトルだけでは伝わらないアクションの詳細・影響範囲 |
| プライマリアクションボタン | 必須 | アクションを実行するためのボタン |
| キャンセルボタン | 必須 | アクションをキャンセルするためのボタン |

**ライティングルール：**
- タイトルは動詞を含む短い文で記述します（例：「削除しますか？」「変更を保存しますか？」）
- アクションの影響が大きい場合は説明文を設けて詳細を補足します
- プライマリアクションボタンのラベルは、実行する操作を示す動詞にします（例：「削除する」「保存する」）。「OK」「はい」など曖昧な表現は避けます
- キャンセルボタンのラベルは「キャンセル」を基本とします

## 振る舞い

[dialog](./index.md) の振る舞いは dialog 全体で共通。

## Do

- タイトルに動詞を含め、実行内容を明確にする
- プライマリアクションボタンのラベルは操作を示す動詞にする（「削除する」「保存する」）
- 影響が大きいアクションには説明文を設ける

## Don't

- 「OK」「はい」など曖昧なボタンラベルにしない
- フォーム入力を action-dialog に含めない → [form-dialog](./form-dialog.md) を使う
- 情報通知だけの目的で使わない → [information-dialog](./information-dialog.md) を使う
