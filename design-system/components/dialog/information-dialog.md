# information-dialog

ユーザーへの情報通知や内容の提示を目的とするモーダルダイアログです。アクションの選択を求めず、ユーザーに内容を確認させることに特化します。

## いつ使うか

- 重要なお知らせ・アップデート内容の提示
- 処理完了・エラー詳細など、概要以上の詳細内容の通知
- 利用規約・注意事項など、ユーザーが読んだことを確認する必要がある情報の提示

## いつ使わないか

- 「実行する」「キャンセルする」などアクションの二択が必要な場合 → [action-dialog](./action-dialog.md) を使う
- フォーム入力を伴う場合 → [form-dialog](./form-dialog.md) を使う
- 短い一時通知 → [snackbar](../snackbar.md) を使う
- ページ内に常時表示すべき情報 → [inline-notification](../inline-notification.md) を使う

## バリアントプロパティ

| プロパティ | 値 | 説明 |
|-----------|-----|------|
| width | medium / large | ダイアログの幅 |

## コンテンツルール

| 要素 | 必須 | 説明 |
|------|:----:|------|
| バックドロップ | 必須 | ダイアログ背後の半透明の暗幕 |
| タイトル | 必須 | 提示する情報の内容を端的に示す見出し |
| 説明文 | 任意 | 詳細情報や提示内容の本文 |
| 閉じるボタン（テキスト） | 任意 | ユーザーが内容を確認したことを示すテキストボタン（例：「閉じる」「確認しました」） |

**ライティングルール：**
- タイトルは情報の種類・内容を端的に示す
- 閉じるボタンのラベルは「閉じる」または「確認しました」を基本とする
- アクションを促すプライマリボタン（削除・保存など）は配置しない

## Do

- タイトルで情報の種類・内容を端的に示す
- 閉じるボタンのラベルは「閉じる」「確認しました」にする
- 重要度の高い情報をユーザーが明示的に閉じるまで表示を維持する

## Don't

- アクションを促すプライマリボタン（削除・保存など）を配置しない
- 短い一時通知に使わない → [snackbar](../snackbar.md) を使う
- フォーム入力を含めない → [form-dialog](./form-dialog.md) を使う
