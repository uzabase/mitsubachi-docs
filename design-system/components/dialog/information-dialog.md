# information-dialog

information-dialog は、ユーザーへの情報通知や内容の提示を目的とするモーダルダイアログ（画面全体を覆うオーバーレイ上に表示される対話型パネル）です。バックドロップ（半透明の暗幕）で背景UIへの操作をブロックし、ユーザーの注意を集中させた上で内容を提示します。アクションの選択を求めるボタンは持たず、ユーザーに内容を確認させることに特化します。

## 使いどころと選び方

### 使うべきシーン
- 重要なお知らせ・アップデート内容の提示
- 処理完了・エラー詳細など、概要以上の詳細内容の通知
- 利用規約・注意事項など、ユーザーが読んだことを確認する必要がある情報の提示

### 使わないほうがよいシーン
- 「実行する」「キャンセルする」などアクションの二択が必要な場合（→ [action-dialog](./action-dialog.md) を使います）
- フォーム入力を伴う場合（→ [form-dialog](./form-dialog.md) を使います）
- 短い一時通知（→ [snackbar](../snackbar.md) を使います）
- ページ内に常時表示すべき情報（→ notification または inline-notification を使います）

### 他コンポーネントとの違い・使い分け
- **[action-dialog](./action-dialog.md) との違い**：action-dialog はアクションの選択を目的とし、プライマリアクションボタンとキャンセルボタンの2ボタン構成を持ちます。information-dialog は情報の提示のみを目的とし、閉じる操作のみを持ちます。
- **[form-dialog](./form-dialog.md) との違い**：form-dialog は入力フィールドを持ちます。information-dialog は読み取り専用です。
- **snackbar との違い**：snackbar は一時的な操作フィードバックに特化し自動消去します。information-dialog は重要度の高い情報をユーザーが明示的に閉じるまで表示を維持します。

## 構成とルール

### バリエーション・状態
- **width**：`medium`（標準幅）と `large`（幅広）の2種類があります

### コンテンツルール

information-dialog は以下の要素で構成されます。

| 要素 | 必須 | 説明 |
|------|:----:|------|
| バックドロップ | 必須 | ダイアログ背後の半透明の暗幕 |
| タイトル | 必須 | 提示する情報の内容を端的に示す見出し |
| 説明文 | 任意 | 詳細情報や提示内容の本文 |
| 閉じるボタン（テキスト） | 任意 | ユーザーが内容を確認したことを示すテキストボタン（例：「閉じる」「確認しました」） |

**ライティングルール：**
- タイトルは情報の種類・内容を端的に示します
- 閉じるボタンのラベルは「閉じる」または「確認しました」を基本とします
- アクションを促すプライマリボタン（削除・保存など）は配置しません

## 振る舞い

[dialog](./index.md) の振る舞いは dialog 全体で共通。

## Do

- タイトルで情報の種類・内容を端的に示す
- 閉じるボタンのラベルは「閉じる」「確認しました」にする
- 重要度の高い情報をユーザーが明示的に閉じるまで表示を維持する

## Don't

- アクションを促すプライマリボタン（削除・保存など）を配置しない
- 短い一時通知に使わない → [snackbar](../snackbar.md) を使う
- フォーム入力を含めない → [form-dialog](./form-dialog.md) を使う
