# checkbox

ひとつの項目に対して選択・解除を行うためのコンポーネント群。

> mockup で再現する場合は `mockup-kit/mitsubachi-mockup.css` の `.mi-checkbox` + `.mi-checkbox-label`（グループは `.mi-choice-group`） を使う（自作しない）。

## 使い分け

| コンポーネント | 用途 |
|---|---|
| [checkbox](./checkbox.md) | 選択ボックス単体。ラベルなしで使用する |
| [checkbox-text](./checkbox-text.md) | チェックボックスとラベルテキストの組み合わせ |
| [checkbox-text-group](./checkbox-text-group.md) | 複数のcheckbox-textをグループとしてまとめる |
| [checkbox-text-group-unit](./checkbox-text-group-unit.md) | checkbox-text-groupにラベル・必須表示・補足テキストを加えたフォーム用セット |
