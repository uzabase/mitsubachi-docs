# link-menu-item

link-menu-item は、クリックすると別ページへ遷移するメニューアイテムです。HTML の `<a>` タグで実装されるため、ブラウザ標準のリンク挙動（新しいタブで開く、右クリックメニューなど）を持ちます。

## 使いどころと選び方

### 使うべきシーン
- メニュー内のアイテムで、クリック時にページ遷移（href による URL 移動）が必要なとき
- 新しいタブで開く、外部 URL へのリンクなど、リンクとしての挙動が求められるとき

### 使わないほうがよいシーン
- アクションを実行するだけの場合（→ [action-menu-item](./action-menu-item.md) を使います）
- disabled 状態でリンクを無効化したい場合（`<a>` タグの disabled は標準では存在しないため、設計上の注意が必要です）

### 他コンポーネントとの違い・使い分け
- **[action-menu-item](./action-menu-item.md) との違い**：link-menu-item は `<a>` タグで実装されるため、ブラウザのリンク挙動を持ちます。コマンドの実行には action-menu-item を使います。

## 構成とルール

### バリエーション・状態

#### State
- `default`：通常の状態。
- `hover`：マウスカーソルが重なっている状態。オーバーレイで視覚フィードバックを表示します。
- `active`：クリック・タップ中の状態。
- `focus`：フォーカスされている状態。フォーカスリングで視覚化します。

#### New window
- `True`：外部リンクアイコンを表示
- `False`：外部リンクアイコンを表示しない

### コンテンツルール
- ラベルはリンク先の内容を端的に表す文言で記述します
- ラベルは1行に収まる長さとします
- 外部サイトへのリンクの場合は、外部リンクアイコンを表示することを検討します

## 振る舞い

- クリック（タップ）でページ遷移が発生します
- 右クリックで「新しいタブで開く」などのブラウザ標準のコンテキストメニューが表示されます
- hover 時に背景色が変化します
- キーボードの上下矢印キーでフォーカスを移動できます
- Enter でリンク先へ遷移します

## Do

- ページ遷移が目的のアイテムにはこのコンポーネントを使う
- 外部リンクには New window を true にして外部リンクアイコンを表示する

## Don't

- コマンドの実行に使わない → [action-menu-item](./action-menu-item.md) を使う

## 役割と目的
- メニュー内のアイテムとしてページ遷移を提供します
- アクションの実行ではなく、URL への遷移が目的のアイテムに使います
- [menu](./index.md) コンポーネント内で使うアイテムとして機能します
