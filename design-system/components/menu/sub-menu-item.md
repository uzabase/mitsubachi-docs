# sub-menu-item

sub-menu-item は、サブメニューを持つメニューアイテムです。右端に「>」（シェブロン）アイコンを表示することで、この項目にサブメニューがあることをユーザーに示します。

## 使いどころと選び方

### 使うべきシーン
- アクションの選択肢が多く、カテゴリに分けて階層表示したいとき
- 階層は最大2階層まで（menu → sub-menu）使えます

### 使わないほうがよいシーン
- 2階層を超える深い階層が必要な場合（ユーザーにとって複雑になりすぎるため、別の設計を検討します）
- サブメニューを持たない単純なアクションの場合（→ [action-menu-item](./action-menu-item.md) を使います）

### 他コンポーネントとの違い・使い分け
- **[action-menu-item](./action-menu-item.md) との違い**：sub-menu-item はそれ自体がアクションを実行せず、サブメニューを展開するトリガーとして機能します。クリックではなくホバーでサブメニューが開きます。
- **menu-item-group との違い**：menu-item-group は同一階層内でのグループ化です。階層を増やす場合は sub-menu-item を使います。

## 構成とルール

### バリエーション・状態

#### State
- `default`：通常の状態。
- `hover`：マウスカーソルが重なっている状態。サブメニュー展開中。オーバーレイで視覚フィードバックを表示します。
- `active`：クリック・タップ中の状態。
- `focus`：フォーカスされている状態。フォーカスリングで視覚化します。
- `disabled`：操作不可の状態。グレーアウトで表示されます。

#### Show icon
- アイコンの有無を切り替えられます（任意）

### コンテンツルール
- 右端に「>」アイコンを必ず表示します
- ラベルはサブメニューのカテゴリを端的に表す名詞または名詞句で記述します
- ラベルは1行に収まる長さとします

## 振る舞い

**サブメニューの開き方**
- マウス操作：親メニューの sub-menu-item にホバーするとサブメニューが展開します

**サブメニューの表示位置**
- 左右：基本は右。右側にスペースが確保できないときのみ左に表示します

**サブメニューの閉じ方**
- 1回目の ESC でサブメニューを閉じます。2回目の ESC で親メニューも閉じます
- サブメニューを含むメニュー全体の外側をクリックすると、すべてのメニューが閉じます
- サブメニュー内の menu-item をクリックすると、サブメニューと親メニューの両方が閉じます
- 親メニューの sub-menu-item からホバーが外れたとき、サブメニューが閉じます

> メニューが表示されている状態でブラウザをスクロールしても、メニューは閉じません。

## Do

- 選択肢が多い場合にカテゴリごとに階層化して整理する
- 階層は最大2階層までに留める

## Don't

- 2階層を超える深い階層にしない（ユーザーにとって複雑になりすぎる）
- サブメニューを持たない単純なアクションには使わない → [action-menu-item](./action-menu-item.md) を使う

## 役割と目的
- 選択肢を階層化して整理します
- 親メニューのアイテムとしてサブメニューの起点になります
- [menu](./index.md) コンポーネント内で使うアイテムとして機能します
