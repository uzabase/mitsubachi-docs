# sp-symbol

Speeda のシンボルマークのみを表示するコンポーネントです。ファビコンやアイコン的な用途など、省スペースな場所で使用します。

## 使いどころと選び方

### 使うべきシーン
- ファビコンとして使用する場面
- アイコン的な用途でブランドを示す場面
- スペースが限られた場所で Speeda を表現する場面

### 使わないほうがよいシーン
- テキスト付きの Speeda ロゴが必要な場合 → [sp-logo](./sp-logo.md)
- 親会社 Uzabase のロゴを表示する場合 → [ub-logo](./ub-logo.md)

## 構成とルール

### バリエーション・状態

| プロパティ | 値 | 説明 |
|-----------|-----|------|
| inverse | false / true | 明るい背景用（通常）/ 暗い背景用（白抜き） |

### コンテンツルール
- ロゴのサイズは用途に応じて調整可能だが、アスペクト比は維持する
- 最小サイズを下回らないようにする（視認性確保）

## Do
- ロゴの周囲には十分な余白（クリアスペース）を確保する
- 暗い背景では `inverse=true` を使用する

## Don't
- ロゴのアスペクト比を変えない
- 他の要素とロゴを密着させない
- 最小サイズを下回るサイズで使用しない
