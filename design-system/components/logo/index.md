# logo

Speeda および関連ブランドのロゴを表示するコンポーネント群。

> mockup で再現する場合は `mockup-kit/mitsubachi-logos.css` を追加読み込みして `.mi-logo--*` を使う（自作しない）。

## 使い分け

| コンポーネント | 用途 |
|---|---|
| [speeda-logo](./speeda-logo.md) | ヘッダー、フッター、ログイン画面など Speeda ロゴを表示する場合 |
| [uzabase-logo](./uzabase-logo.md) | フッターなど親会社 Uzabase のロゴを表示する場合 |
| [symbol](./symbol.md) | ファビコン、アイコン的な用途など省スペースな場所でシンボルマークのみ表示する場合 |
