table — mockup kit 見本

データを行と列で構造化するテーブル。.mi-table が本体、.mi-table--list でリストビュー。 行 hover は tr:hover（行全体がハイライト）、選択行は tr[aria-selected="true"]、 ソート可能ヘッダーは <th aria-sort="ascending|descending"> でラベル・アイコンが selected 色になる。 セルの種類は th/td のクラスで表す（数値 __num / 行見出し __row-header / 選択 __check / 行操作 __actions）。

グリッドビュー（既定。グレーヘッダー・全周罫線。全 content-type 網羅）

content-type: checkbox(__check・全選択/行選択) / header(__row-header・行見出し=太字) / text(素の td・リンク可) / slot(td に .mi-tag 等を直接) / number(__num・右寄せ等幅) / Null(値が無いセルは「–」en dash が既定) / icon-button(__actions)。2 行目は選択行（aria-selected="true" ＋ checkbox チェック）。

ソート状態（ヘッダー。適用中はラベル・アイコンが selected 色 / hover で面が濃くなる）

ソート可能な列は aria-sort を付ける。未ソートは arrow-up-down、昇順は arrow-up-small、降順は arrow-down-small。マウスを乗せるとヘッダー面が濃くなる。
トグル順序（Figma 107-8889）: ヘッダーのセル全体をクリックして Default → 昇順 → 降順 → 解除（昇順でも降順でもない状態。並び順はテーブル次第）と遷移。各状態に tooltip を併用。ソート機能が無い列のヘッダーには hover 等の状態変化を付けない。列単位の操作が要る場合はヘッダーから action-menu を開く。
