# chart-color / グラフの配色

棒グラフ・円グラフ・折れ線グラフで、**凡例にどの色を割り当てるか**のルール。

> **⚠ このルールは暫定です。**
> - 値の正は Notion「[グラフの配色ルール（暫定）](https://www.notion.so/uzabase/38158a33603580f39454e3bdaa961360)」（ステータス=進行中）。**Figma のトークンには未反映**で、Figma MCP では取得できない
> - **primitive color のカラーパレットを再検討する予定**があり、それが済んだら多色使いを再検討する。そのとき値ごと変わる
> - 現パレットで多色使いにすると明るすぎてチカチカするため、暫定的に**色相を抑えた配色**にしている。アクセシビリティ的には多色かつ棒グラフを薄い色にする方が適切という認識はある
> - HEX は `mockup-kit/tokens.css` の `--chart-*` が持つ（このファイルは値を持たない）

---

## 棒グラフ・円グラフ

### 色相とシェード

**5色相**（Blue → Viridian → Green → Leaf → Lemon）× **5シェード**（`25` 最薄 / `60` / `100` / `140` / `160` 最濃）で、**最大25凡例**まで対応する。

凡例数が増えるにつれて、上の順で色相を切り替える。

| 凡例の範囲 | 色相 |
|---|---|
| 1〜5 | Blue |
| 6〜10 | Viridian |
| 11〜15 | Green |
| 16〜20 | Leaf |
| 21〜25 | Lemon |

### 割り当てのルール

- **Blue は `60` を基準**にして、凡例数に応じて濃い方向・薄い方向へ均等に広げる
- Blue の5色をすべて使ったら次の色相へ切り替える
- **Blue 以外の色相は、必ず最も濃い `160` から順に**割り当てる（`160` → `140` → `100` → `60` → `25`）

### 凡例1〜5（Blue）

凡例の数によって使うシェードが変わる。

| 凡例数 | 1番目 | 2番目 | 3番目 | 4番目 | 5番目 |
|---|---|---|---|---|---|
| 1 | `60` | | | | |
| 2 | `100` | `60` | | | |
| 3 | `100` | `60` | `25` | | |
| 4 | `140` | `100` | `60` | `25` | |
| 5 | `160` | `140` | `100` | `60` | `25` |

### 凡例6番目以降（Viridian / Green / Leaf / Lemon）

どの色相も同じ順番で、**必ず `160`（最濃）から始まり `25`（最薄）で終わる**。

| 色相内の順番 | シェード |
|---|---|
| 1番目 | `160` |
| 2番目 | `140` |
| 3番目 | `100` |
| 4番目 | `60` |
| 5番目 | `25` |

## 折れ線グラフ

**16色**を下の順に使う。**9番目以降は破線**（`8 4`）にする。

## mockup で使う

色は `mockup-kit/mitsubachi-mockup.css` のクラスを当てる（HEX を直書きしない）。

| 用途 | クラス |
|---|---|
| 棒・円グラフの面 | `.mi-chart-fill--<色相>-<シェード>`（例: `.mi-chart-fill--blue-60` / `.mi-chart-fill--viridian-160`） |
| 折れ線の線 | `.mi-chart-line--<1〜16>`（**9番目以降は破線が自動で付く**） |
| 凡例のマーカー | 上のクラスをそのまま使う（`background-color` も設定されている） |

`.mi-chart-fill` は `background-color` と `fill` の両方を持つので、`div` で組んだバーでも SVG の `rect` / `path` でも使える。基底クラス単独（`.mi-chart-fill` / `.mi-chart-line`）は凡例1つのときの既定色になる。

> **グラフ本体（軸・目盛り・凡例のレイアウト）は kit にありません。** 組む場合は `<!-- ds-exception: 理由 -->` を書いて申告する（SVG を直接置くと `tools/check-mockup.py` の層1で warn も出る）。棒グラフの見本を kit に用意するかは検討中（[BACKLOG.md](../../BACKLOG.md) の A-5）。
