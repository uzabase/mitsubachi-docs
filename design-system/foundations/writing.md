# writing / 文言

UI に出す日本語のルール。**モックの文言もこれに従う**（文言のブレは見た目のブレと同じくらい目につく）。

固有名詞・数値の表記は Speeda の画面で使われている形に合わせる。迷ったら「短く、具体的に、次の行動がわかるように」。

---

## 基本

- **敬体（です・ます）**で書く。常体（だ・である）は使わない
- ユーザーを主語にした指示口調（「あなたは〜」）にしない。操作の対象を主語にする
- 1文は40文字程度まで。長い説明は文を分ける
- 感嘆符（！）・絵文字は使わない
- 半角カタカナ、機種依存文字は使わない
- 英数字は半角。英語と日本語の間にスペースを入れない（「AI要約」「CSVでエクスポート」）
- 専門用語をそのまま出さない。出すなら初出で言い換えを添える

## ボタン・アクションのラベル

| | 書き方 |
|---|---|
| **Do** | 動詞で終える（「保存する」「エクスポートする」「削除する」）。何が起きるかが読めば分かる |
| **Don't** | 名詞・体言止め（「保存」「エクスポート」）／「OK」「はい」「いいえ」だけ／「送信」のような汎用語 |

- 長さは**8文字程度まで**を目安にする（`.mi-button` は折り返さない）
- primary ボタンのラベルは、その画面の目的そのものにする（「この条件で検索する」）
- キャンセル側は「キャンセル」で固定する（「やめる」「戻る」と混ぜない）
- 破壊的操作（`--danger`）は対象を含める（「この検索条件を削除する」）
- icon-button の `aria-label` も同じ規則で書く（「サイドナビを折りたたむ」）

## 見出し・ラベル

- ページタイトル・セクション見出しは**体言止め**（「競合企業の比較」）。末尾に句点を付けない
- 入力欄のラベルは名詞で短く（「企業名」「決算期」）。末尾にコロンを付けない
- 必須は `.mi-label-unit__required` で示す。「（必須）」と文字で書かない
- 補足は `.mi-label-unit__support` に入れる。ラベルに括弧書きで足さない

## エラー・検証メッセージ

**「何が起きたか」＋「どうすればよいか」**の2要素で書く。原因だけを書いて終わらない。

| | 例 |
|---|---|
| **Do** | 「企業名を入力してください」／「通信に失敗しました。時間をおいて再度お試しください」 |
| **Don't** | 「エラーが発生しました」／「不正な値です」／「入力値が正しくありません」 |

- ユーザーを責める表現（「間違っています」）にしない
- 技術的な内部語（ステータスコード・例外名・API 名）を出さない
- 入力欄のエラーは `.mi-error-text`（欄の直下）、処理全体のエラーは `.mi-inline-notification--error`

## 空状態（データが0件のとき）

**状況**（なぜ空か）＋**次の行動**（どうすれば埋まるか）を書き、可能なら操作を1つ置く。

| 場面 | 書き方 |
|---|---|
| まだ登録していない | 「競合企業がまだ登録されていません」＋「競合企業を追加する」ボタン |
| 検索結果が0件 | 「条件に一致する企業が見つかりませんでした」＋「条件を変更して再検索してください」 |
| 権限が無い | 「この情報を表示する権限がありません」＋管理者への連絡を促す（403 は `templates/error-403.html`） |

- 「データがありません」だけで終わらせない
- 検索0件では、絞り込み条件を外す導線を示す

## 確認ダイアログ

- タイトルは短い疑問形（「この条件を保存しますか？」）
- 本文は結果を書く。取り消せない操作は**取り消せないことを明記**する（「削除すると元に戻せません」）
- ボタンは動詞（「削除する」／「キャンセル」）。「はい」「いいえ」にしない
- 確認が不要な操作にダイアログを出さない（`.mi-snackbar` で結果を知らせるだけにする）

## 通知の文言

| 使うもの | 文言の形 | 例 |
|---|---|---|
| `.mi-snackbar` | 完了の報告（過去形・体言＋しました） | 「検索条件を保存しました」 |
| `.mi-inline-notification` | その場所の状況説明 | 「一部の指標は最新期の開示がありません」 |
| `.mi-banner` | 画面全体・サービス全体の告知 | 「7月30日 2:00〜4:00 にメンテナンスを実施します」 |
| `.mi-tooltip` | 補足のみ（1行・句点なし） | 「昇順に並べ替え」 |

## 数値・単位・日付

- 数字は半角、3桁区切りのカンマを入れる（`1,240`）
- 単位は数値の後ろに続ける（`1,240億円` `8.2%` `12社`）。表では単位を列見出しに出し、セルは数値だけにする
- 数値セルは `.mi-table__num`（右寄せ）に置く
- 増減は `.mi-tag--positive` / `--negative` で示し、符号を明示する（`+3.2%`）。文字色は変えない
- 日付は「2026年7月29日」。年が自明な文脈では「7月29日」。スラッシュ区切りは表・グラフの軸のみ
- 期間は波ダッシュではなく「〜」（「2026年4月〜6月」）
- 決算期は「2026年3月期」
- 相対表記は「3日前」まで。それより古いものは日付で書く
- **値が無いセルは「–」（en dash）**（`components/table.md`）。「N/A」「なし」「0」で代用しない

## 表記を統一する語

| 使う | 使わない |
|---|---|
| ログイン / ログアウト | サインイン / サインアウト |
| 企業 | 会社（法人一般を指す場合） |
| 絞り込む | フィルタする / フィルタリング |
| 並べ替える | ソートする |
| エクスポートする | ダウンロードする（ファイル生成を伴う場合） |
| 削除する | 消す / 破棄する |
| 保存する | 登録する（既存データの更新の場合） |
| AI要約 | AIサマリー / 自動要約 |

## AI 機能の文言

- AI の出力には**確認を促す一言**を添える（`.mi-ai-chat__disclaimer`）。「内容の正確性は必ずご確認ください」
- AI の動作を擬人化しない（「AIが考えています」ではなく「要約を作成しています」）
- 実行ボタンは `.mi-ai-button` を使い、AI が動くことがラベルから分かるようにする（「AIで要約する」）
- 生成中は `.mi-loading--ai` を使い、待ち時間の目安があれば書く
